# T16.4 契约设计与自评审

2026-10-02，保留准备提交 cdbabdd。依据已确认范围和前置审计，先写 OpenAPI 0.30.0、独立内部协议和新事件，再实现生产者/消费者。不改变产品、页面或既有事件版本。

## 决策与失败场景

- Operation 维护稳定公告、不可变版本、独立确认、同公告/学生唯一消息、命令幂等、Outbox、消费台账与分页投递工作。确认持公告锁并要求 expectedRevision；旧版本确认或读命令409，重放旧确认不确认新版本。改版事务立即重置已有消息/确认；异步补齐当次学生，旧事件不得覆盖新消息。撤回读404，审计保留。
- Learning 向前新增报名有效区间，报名/取消与区间/访问事件同事务。收件人查询以触发时间落在半开区间[start,end)为准，按 learnerId 游标最多100人。重新报名不覆盖旧区间；投递再查当前ACTIVE，课程owner排除。迁移只初始化现有最后区间，不重放部署前历史事件。跨域HTTP准入读取不承诺分布式原子快照。
- 真正开放事实以 max(publishedAt, opensAt) 为触发时点；空 opensAt 用 publishedAt。持久 pending/opened/failed 触发记录、课程→测评锁、实时Course可用性和截止检验，最多10场/轮。暂停不消耗故障次数，恢复沿用原顺延；恢复先追平任务时钟再计算开放点。依赖故障有限退避，耗尽保留FAILED，不自动重放。
- HOMEWORK/EXAM 的开放/截止变更/立即结束以新 Learning 事件v1发布；PRACTICE严格排除。截止/结束和事件同领域事务；暂停恢复自动补时沿用原规则，不另制造教师截止变更。开放投递重试再校验当前可作答，暂停/结束时不发可作答提醒。
- 独立 Operation 内部只读秘密，固定operation-service caller，Course只返回owner/发布/暂停/水位/邮箱，Learning返回有界历史名单/当前资格/任务安全事实，IAM只裁决本人申请目标。无跨库SQL、无写暂停权限、无正文/材料/原因副本。
- 列表、计数、目标、已读共用实时资格；数据库快照和HTTP每批100条，不设累计数量上限。暂停/恢复消息仍可告知ACTIVE学生通用状态；普通目标成功加载后显式read，公告只走confirm。read-all不改公告，依赖失败回滚。
- 独立edu.operation.notifications.v1队列绑定既有信号和新事件，三次消费尝试后独立DLQ。eventId与工作同事务；工作每次只推进一页，行锁防双实例重复，失败最多五次/页，成功后重置页次数；重启从保存游标恢复。Outbox mandatory/confirm最多20次，耗尽FAILED；无TTL、无删除、无历史FAILED重放、无purge。

## 评审结论

已对照四类消息、后报名/退课、并发改版、旧确认、到时开放、暂停/恢复、乱序、依赖失败和队列隔离逐项检查。普通revision、事务、主键/唯一约束和分页游标足以保护本次状态；不引入hash/baseline/gate。实现后必须以真实多JVM Gateway/领域HTTP、MySQL、RabbitMQ和故障专项验证，未运行的验证不得记为通过。
