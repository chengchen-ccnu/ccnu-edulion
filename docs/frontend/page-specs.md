# 前端页面与信息架构规格

> 状态：平台级唯一事实来源
>
> 维护者：总控任务
>
> 最近审计：2026-08-30
>
> 适用范围：`student-web`、`teacher-web`、`admin-web` 及其共享前端包

## 1. 使用规则

本文冻结三端的路由、页面职责、访问能力、核心状态和任务归属。OpenAPI 决定接口字段，本文决定这些接口应被哪个页面消费；两者均不能由功能任务自行猜测。

- 总控任务负责新增、删除或改变页面职责，并同步总体架构、backlog 和任务依赖。
- Txx 功能任务只能实现本文已分配给自己的页面区域；发现规格不足时停止扩展，向总控报告差异。
- 修改路由、导航名称、跨应用跳转或页面职责时，必须先更新本文，再修改实现。
- 未接通真实契约的入口不得伪装成可用功能。可以不展示，或在确有产品价值时展示明确、不可操作的阶段说明；禁止用假数据、空成功页或永久占位页冒充完成。
- 页面完成不等于路由可打开。必须同时覆盖权限、加载、空态、部分失败、业务错误、离线、响应式、键盘操作和深链接恢复。

当前 `main` 已包含 T12D 账号生命周期与 Redis 身份安全后端及 OpenAPI 0.17.0；T12B 继续在既有稳定路由内提供学生练习/考试、双视图结果、错题本和教师测评管理，课程媒体、三端稳定导航、教师题库、受控历史 JSON/知识图谱迁移、学习测评后端及我的学习/进度前端均沿用已合并实现。T12E 的工程、唯一身份区域路由和既有权限前置已经满足，但协议版本权威来源、身份绑定范围和帮助反馈边界仍须由总控审计确认；确认前不得由前端硬编码或伪造。T12E 只能消费生成客户端实现注册、找回/重置密码、账号安全、教师申请及公共协议页面，不得另建教师/管理端登录注册入口。T11C、T12F～T12G 和 T16A 继续分别收口作业规则、课程内容/播放器、高频进度和门户缓存。

## 2. 不可破坏的信息架构边界

### 2.1 课程详情不是课程学习页

`/courses/:courseId` 是公开课程落地页，服务于了解、比较和决定是否学习：展示封面、简介、教师、目录预览、评价摘要、访问规则，以及“开始学习/继续学习/试看/报名”行动。

`/learn/:courseId/:lessonId` 是受保护的学习工作区，服务于持续学习：承载视频或图文内容、章节目录、上一课/下一课、进度、笔记、资料、练习和课时上下文 AI。正式播放器不得嵌回公开课程详情页。

### 2.2 公共身份、学习能力和教学能力相互独立

- 课程中心对游客、学生、教师和管理员保持角色中立。
- 学习空间按 `learning:access` 和课程访问事实授权，不永久绑定 `STUDENT` 角色。T11 已按能力建立后端边界，T12 应允许同时具有教学和学习能力的教师进入学习空间。
- 教师工作台按 `teaching:access` 和课程所有权授权；“课程中心”和“教学管理”不是同一列表。
- 管理端按 `administration:access` 授权，前端隐藏入口不替代服务端权限校验。

### 2.3 三个产品空间

| 空间 | 用户目标 | 主要入口 |
|---|---|---|
| 公共课程门户 | 发现和了解课程 | 首页、课程列表、课程详情 |
| 学习空间 | 继续学习、练习、复习和答疑 | 我的学习、课程学习、练习、结果、错题、AI |
| 创作与治理空间 | 创建课程、管理教学、审核与运营 | 教师工作台、管理端 |

统一登录由 `student-web` 物理承载，但文案和行为必须角色中立。登录后根据能力进入唯一工作台、工作台选择页或经过白名单验证的原始目标。

### 2.4 账号生命周期与教师能力

- `/login`、注册、密码找回和公共协议均由 `student-web` 的角色中立身份区域物理承载；教师端、管理端不得复制第二套表单。
- 自主注册只创建普通学习账号并授予 `learning:access`。管理员不允许公开注册；普通用户通过教师申请、资质上传和管理员审核后，由 IAM 为同一账号增加 `teaching:access`，不创建第二个教师账号。
- 注册验证码、发送冷却、失败次数和短期锁定属于 Redis 短期安全状态；用户、唯一身份、角色、协议同意、教师申请、Refresh Session 和审计事实仍由 MySQL 保存。
- 修改/重置密码、禁用账号或管理员强制下线必须递增持久化账号会话版本并撤销 Refresh Session；Redis 只缓存当前版本，不能作为唯一撤销事实。
- 身份页面必须支持 `422` 字段错误、`429 Retry-After`、验证码过期、目标已占用、离线和服务故障；不得通过不同错误泄露手机号、邮箱或账号是否存在。

### 2.5 全局应用壳不可变规则

三端全局应用壳均分为品牌区、主导航区和账号工具区。页面切换、登录状态、当前角色和功能逐步上线只能改变入口的激活/启用状态，不能改变主导航的标签、顺序或位置。

- 品牌区始终显示 `Edu Lion`，不得把“学生学习中心”“课程中心”“教师工作台”或当前页面名称写入品牌标题。当前页面标题、课程名和面包屑属于页面内容区。
- 主导航使用下文冻结的固定槽位。未交付的槽位保留原位置，以“建设中”状态和 `aria-disabled=true` 明确不可操作，不得链接到 `PlaceholderPage`、空成功页或不存在的路由；对应任务完成后只启用槽位，不新增、改名或换序。
- 账号工具区固定容纳通知、工作台控制和账号控制。匿名时账号控制显示“登录”，登录后在同一位置显示头像/账号菜单；单工作台账号显示当前工作台，多工作台账号在同一位置提供切换，不向主导航临时插入“选择工作台”。
- 当前路由只改变 `aria-current` 和视觉高亮：课程列表/详情高亮课程中心，学习页和我的学习高亮我的学习，作答/结果/错题高亮练习中心，AI 会话高亮 AI 答疑。
- 响应式只能把同一组入口折叠为菜单、抽屉或横向滚动，不能删减、重排或改名。键盘焦点顺序必须与冻结顺序一致。
- `AppShell` 等共享包只渲染品牌、导航模型和具名区域，不包含学生/教师/管理员角色判断；各应用负责提供符合本文的固定导航模型，服务端权限仍是最终授权依据。

### 2.6 学生端固定顶栏

| 顺序 | 固定标签 | 目标 | 启用任务 | 当前未启用时的表现 |

| 1 | 首页 | `/` | T17A | 固定显示“建设中”，不进入现有首页占位路由 |

| 3 | 我的学习 | `/my-learning` | T12A | 已启用；`/learn/...` 与 `/my-learning` 共用这一固定高亮组 |

学生端账号工具区从左到右固定为：通知、工作台、账号。通知由 T17A 启用；工作台槽位始终存在；账号槽位在“登录”和账号菜单之间切换。学习页也保留同一全局顶栏，课程上下文和退出学习操作放在页面内容区。

### 2.8 管理端固定导航

管理端主导航采用固定左侧栏，顺序为：工作台、教师审核、课程审核、内容治理、运营配置、数据报表、系统管理，分别对应第 5 节既有路由。顶部只保留 `Edu Lion` 品牌、当前“管理端”工作台标识以及通知/工作台/账号工具，不再重复放一套会随页面变化的主导航。

T17C 之前未交付的管理入口必须显示“建设中”且不可进入占位页；T17C 只能逐项启用既有槽位。收起侧栏、移动端抽屉和权限禁用不得改变标签、顺序或活动路由映射。

### 3.1 课程详情行动规则

- 匿名用户点击“开始学习”或“试看”时进入统一登录，并保留经过白名单验证的 `/learn/...` 回跳。
- PUBLIC 课程进入第一条可学习课时；已有进度时行动显示“继续学习”并定位最后课时。
- ENROLLMENT_REQUIRED 课程只允许未报名用户试看 `previewable=true` 课时；非试看内容明确提示需要报名，不创建假报名。
- T11/T12A 已接通报名入口与学习域契约；课程详情不得直接推断报名成功或播放权限。
- 目录项目可以展示锁定、试看和类型，但正式内容始终在学习页打开。
- 收藏和评价只能消费 T16 服务端事实；评价资格由报名/学习事实在服务端判断，前端不得仅凭“已登录”显示成功。

### 3.2 课程学习页稳定布局

桌面端至少包含：顶部课程上下文、主内容区、可折叠课程目录、上一课/下一课，以及按能力逐步启用的资料/笔记/练习/答疑区域。移动端使用单列内容和目录抽屉，不把桌面侧栏压缩成不可操作窄栏。

T08B 已交付播放器、目录、当前课时、上一课/下一课、退出学习和有限授权刷新；T12A 在本页展示当前视频百分比并接通进度持久化与笔记，整课完成度留在课程详情和“我的学习”。T12B 已在原布局增加当前课时真实测评入口；T12F 在同一路由补齐图文正文、海报、倍速、清晰度、字幕以及课件/附件的领域授权下载，T12G 将普通播放心跳改为 Redis 高频缓冲和可靠批量落库但不改变页面事实语义；T15B 再启用 AI。后续任务不得搬迁播放器或复制学习页。

### 3.3 测评作答、结果与错题稳定工作流

- T12B 已作为一个功能任务一次性交付学生练习/考试、结果和错题本，以及教师测评管理；学生端、教师端和演示数据共用 OpenAPI 0.16.0 生成契约，没有形成平行路由或第二套 DTO。
- 作答区以一道主问题为一个连续页面区块，提供题号导航、上一题/下一题、已答/未答和整卷概览。组合题及有序小问必须处于同一主问题区块，不得拆到不同页面。
- 普通作答允许在正式提交或服务端截止前回看并修改。答案变化后防抖保存，并以定时刷新作为兜底；每次逻辑保存使用稳定请求标识，界面明确区分保存中、已保存和失败。仅仍有未保存答案时才警告离页，旧请求失败不得永久卡住页面。
- 考试时间以服务端为准；浏览器倒计时只展示和提前锁定。本地归零、刷新、系统休眠恢复或本机时间变化后必须重新校准。到期立即锁定输入，只允许提交服务端最后成功保存的草稿；网络恢复后复用同一请求做有限重试，不接受截止后的新答案，也不得无限重试。
- 结果页提供 `view=all` 和 `view=single&question=<序号>` 两种可恢复视图。前者连续显示所有主问题，后者按答题卡逐题查看；组合题始终整体展示。两种视图消费同一份安全结果，不维护第二套结果接口或 DTO。
- 学生提交后始终可见提交回执、本人答案和提交时间。成绩未公布时不显示总分、逐题得分、对错或可推断评分的信息；参考答案未公布时对应区域显示“教师暂未公布参考答案与解析”，但响应本身也必须隐藏数据，不能仅用 CSS 遮挡。
- 只公布成绩时显示最新总分、逐题得分、本人答案和最后更新时间；只公布参考答案时显示本人答案、参考答案和解析，但不显示成绩、得分或对错；两者都公布时才展示完整结果。重新批改后直接呈现最新成绩和最后更新时间，不增加刻意的“成绩已更新”横幅。
- 错题本在当前页面展开单题重做，调用 T11A 独立、有限次数的 redo 接口，立即展示本次结果和剩余次数；不得跳回原测评或重新打开已提交 attempt。

### 4.1 题库页面稳定工作流

- `/teacher/questions` 是题库聚合入口，不把新建、编辑或导入任务详情塞进不可深链接的临时弹层。页面刷新后必须从 URL 和服务端恢复分页、筛选、当前题目或导入任务；主导航的“题库”在上述六条路由中保持同一高亮组。
- 题目作用域固定为 `SYSTEM` 与 `TEACHER`。`SYSTEM` 题由管理员及其系统媒体资产持有，所有教师可检索、查看并在后续组卷契约中引用，但教师不得修改版本、状态或媒体；`TEACHER` 题只对创建教师可见和可写。教师列表必须提供来源筛选，并明确显示只读系统题标识。
- 新建和编辑支持单选、多选、判断、填空、简答与有序组合题。组合题父题及每个子题的题干、选项、答案、解析、知识点和媒体必须通过 T09B 的结构化契约提交；禁止前端把多个子题拼成一个自由文本答案，也不得直接修改历史版本。
- 组合题详情按一张完整试题展示：父题题干、连续编号的小问和题图共用题干区域，答案与解析分别统一展示并在小问之间换行。内部仍保留子题结构用于后续逐问作答/评分，不得因展示合并丢失顺序、答案或知识点。
- 题目编辑与筛选支持小学一至六年级、初中七至九年级；学段切换必须同步约束年级并清除不匹配的知识点，组合题子题继承父题学段/年级。高中知识点保留为平台数据但保持禁用，不得出现在教师选择器或题目写契约中。
- 详情页默认只读展示当前版本并可查看历史版本；版本切换只改变预览，不移动聚合当前指针。发布、归档和编辑均携带当前 revision，`409` 时展示服务端新版本并保留尚未提交的本地内容，由教师决定重新应用。
- 题目内容按受控 Markdown/LaTeX 和安全富文本渲染，禁止直接使用未经清洗的 `v-html`。图片、音频和附件复用 media-service 上传会话及短期访问授权；业务请求只保存 `mediaId`，内联图片使用与当前版本 `QUESTION_IMAGE` 列表一致的稳定占位符恢复原文位置；离开页面时中止上传/轮询、撤销临时 URL 并清理定时器。
- `/teacher/question-imports` 只创建和展示教师本人 CSV/XLSX 私有题导入。历史 JSON 由管理员通过受控脚本和 `/api/v1/admin/**` 契约进行有界 dry-run、筛选、正式导入与精确清理；浏览器和后端均不得扫描服务端绝对路径。
- 管理员历史 JSON 导入仍保持单任务/单批次上限、稳定检查点、`VALID/NEEDS_REVIEW/SKIPPED/FAILED` 投影、明确图片白名单与精确清理，不得用管理员身份绕过格式、知识点、媒体或幂等校验。正式导入的题目及图片分别保存为 `SYSTEM` 题和 `SYSTEM` 媒体资产。
- T09B 未提供的查询、解决或组合题写入能力在 T10 中不得以浏览器内存、Mock 成功或手写 DTO 补齐；发现契约差异时停止对应交互并回报总控。

### 4.2 教师测评稳定工作流

- `/teacher/assessments` 是唯一测评管理入口，在同一路由内通过可恢复的查询参数表达当前 assessment、列表筛选、编辑、题目配置、发布、结果和人工批改面板。课程编排页只携带课程/课时上下文跳转到这里，不复制测评编辑器或发明平行详情路由。
- 教师主动结束整场测评是不可撤销的高风险操作。页面必须先展示仍在作答的影响人数并二次确认；关闭后立即禁止新建或继续写入 attempt，服务端只按各学生最后成功保存的草稿进行有界、幂等结算。
- 参考答案与解析的公布规则固定为：普通练习可在个人提交后自动公布；作业和考试不得在整场关闭前公布；也可在整场关闭且批改完成后自动公布、关闭后由教师手动公布，或永不公布。仅某位学生已经提交不能成为作业/考试泄题的依据。
- 成绩可在整场关闭、草稿结算完成且全部人工批改完成后自动公布，或由教师手动公布。存在待结算草稿、待批人数或待批题目时，页面显示精确数量并禁用公布成绩；服务端必须执行同样校验。
- 成绩公布与参考答案/解析公布是两个互相独立、只能由未公布变为已公布的事实，均不支持撤回，不支持逐学生或定时公布。公布参考答案不要求主观题已经批完，但必须确保整场关闭且草稿结算完成。
- 首期人工批改只做逐份查看待批主观题、录入得分和评语并提交，不实现批量打分或复杂批注。已公布成绩允许重新批改并保留审计；`409` 时保留本地输入，重新载入最新 revision 后由教师确认，不得静默覆盖。
- T11B 已建立上述服务端事实与安全投影；T12B 页面只消费 OpenAPI 0.16.0 重新生成的客户端，关闭、公布、资格和隐藏字段均来自服务端事实。

## 6. 页面状态与交互最低要求

| 状态 | 统一要求 |
|---|---|
| `loading` | 使用稳定骨架，避免布局跳动；长操作显示阶段而非无限转圈 |
| `empty` | 说明为什么为空，并只提供真实可执行的下一步 |
| `partial-error` | 保留已成功区域，允许定向重试失败区域 |
| `401` | 统一登录或单次刷新；禁止循环刷新 |
| `403` | 解释缺少的业务条件，不把越权资源细节泄露给用户 |
| `404` | 资源不存在、未发布或不可见使用不可枚举表达 |
| `409` | 展示版本/状态冲突并要求刷新，不静默覆盖 |
| `422` | 映射字段错误并保留用户输入 |
| `429` | 尊重 `Retry-After`，有限退避，禁止无限重试 |
| `offline/5xx` | 区分网络与服务故障，提供安全重试，不伪造成功 |

所有页面都必须支持刷新和深链接。播放器、上传、考试和 SSE 页面离开时清理实例、请求、定时器和临时 URL。学生端优先适配手机、平板和桌面；教师与管理端优先桌面并保证平板可操作。
