# ADR-0006：历史逐题 JSON 的受控迁移边界

- 状态：Accepted
- 日期：2026-08-12

## 背景

T09 只实现了教师上传的 CSV/XLSX 异步导入。仓库外只读目录中的 44,441 份历史逐题 JSON 具有四种显式题型、显式 `subQues`、HTML/LaTeX、外部图片和路径教材信息；它们不是 T09 已支持的格式。直接递归全量导入会放大错误映射、外链失效、重复题和不可逆清理风险。

## 决策

1. 历史目录由显式启动的迁移客户端逐文件读取。客户端默认 `dryRun=true`、必须设置不超过 1000 的 `maxItems`，按最多 20 项一批提交；当前仓库脚本固定单并发，未来实现也不得超过 4。服务端不接受目录路径，也不自行遍历或一次加载全部文件；同一任务的不同批次由任务行锁串行累计。
2. 新增 `LEGACY_JSON` 批次契约。每项只携带一份 JSON、相对路径中的教材/年级信息和稳定来源键；服务端响应与日志只返回聚合计数、来源键和问题码，不回显题干、答案或原始 JSON。
3. 来源幂等键为 `ownerId + sourceSystem + externalId + dryRun`，让预检与实际导入相互隔离。只读脚本对原始 UTF-8 文件字节计算内容 SHA-256；服务端同时保存相对路径 SHA-256、路径教材/年级、JSON 教材/年级和原始难度。相同键相同哈希是安全重放；相同键不同哈希进入 `NEEDS_REVIEW`，绝不覆盖既有题目。
4. `select_single`、`select_multiple`、`fillin`、`writeout` 映射到现有题型。选项只有在存在明确、完整的 A～H 标记时才拆分；内嵌选项无法可靠拆分、仅由题干暗示的多问、路径与 JSON 元数据冲突均进入 `NEEDS_REVIEW`。
5. 显式 `subQues` 保留输入顺序。子题可使用自身答案；仅当父级答案编号从 1 连续到 N、编号数与子题数完全相等且每段非空时，才允许作为缺失子题答案的保守回退。其他父级汇总答案不得静默拆分，无法验证的组合题只保留来源与问题码并进入复核。
6. HTML 使用标签/属性白名单清洗，去除脚本、事件处理器和危险协议；LaTeX 文本不解释、不重写。`solution` 可为空。外部图片标签先替换为稳定占位，再由 `media-service` 的受限 HTTPS 转存契约生成 `QUESTION_IMAGE mediaId`；`learning-service` 不接入 OSS SDK，不保存外部 URL、Bucket、Object Key 或签名 URL。
7. 批次处理是至少一次语义：`batchId` 和来源键都幂等；每项使用嵌套事务隔离，失败可在新受控任务重试，任务只累计已确认结果。真实验收只允许显式小样本，清理按 importTaskId 精确删除仍为 DRAFT 的本任务题目与来源引用并发布媒体解除事件；全量执行需要另行人工授权。

## 后果

- CSV/XLSX 继续走 T09 的媒体源 + RabbitMQ v1 事件；历史 JSON 使用新的批次 v2 事件/HTTP 契约，两者不会把旧事件版本改写成新语义。
- dry-run 不创建题目、不转存图片，只保存无内容的问题摘要和聚合计数；实际导入才写题目、来源引用及稳定媒体绑定。
- T10 只需消费冻结后的任务/复核投影，不在 T09A 新增页面。T11 以后可读取组合题结构，但本任务不实现组卷、作答或判分。
