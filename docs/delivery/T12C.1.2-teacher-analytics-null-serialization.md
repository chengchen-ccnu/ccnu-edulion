# T12C.1.2 教师学情必需 nullable 字段序列化对齐

## 目标与边界

分支 `codex/t12c1.2-analytics-null-serialization` 对齐 OpenAPI 0.26.1 的九个教师学情 GET 响应。Learning 全局 Jackson 使用 `non_null`，此前真实 HTTP 在值为 null 时会省略 OpenAPI 同时声明为 `required` 的字段。本次仅在 `TeacherAnalyticsDtos` 的六个相关 record 上显式采用 `JsonInclude.ALWAYS`，让合法空值写成 JSON `null`。没有改成绩可见性、权限、字段含义、全局配置、OpenAPI、生成客户端或前端页面。

## 契约盘点与调用流程

九个接口是课程下 `students` 列表、单生 `overview|lessons|tasks|trend`，以及课程 `analytics/overview|lessons|tasks|trend`。它们继续经 Gateway 传递可信身份头，由 Learning 校验 `teaching:access`，经 Course API 校验 owner/当前发布内容，再读取本域持久事实。服务层先完成正式成绩门禁和当前修订裁剪，DTO 仅负责把裁剪后的值输出为 JSON。

OpenAPI 0.26.1 中同时 `required`、允许 `null` 的字段及对应 record：

| 响应 record | 字段 | 合法空值场景 |
|---|---|---|
| `Period` | `dataThrough` | 无已发布课程或无可归属的落库事实 |
| `Student` | `nickname`, `lastActivityAt`, `homeworkAverage`, `examAverage` | 昵称不可用、无活动时间、正式成绩尚不可见或无成绩 |
| `StudentLesson` | `watchedSeconds`, `lastActivityAt` | 非视频课时、无课时活动 |
| `StudentTask` | `lessonId`, `rawScore`, `totalPoints`, `scorePercent`, `rank`, `rankedStudentCount`, `rankingPercent` | 非课时任务、本人未批或成绩门禁未开、班级排名未就绪 |
| `CourseLesson` | `watchedSeconds`, `actualViewerCount`, `averageWatchedPerActiveStudent`, `averageWatchedPerViewer` | 非视频课时 |
| `CourseTask` | `lessonId`, `averageScorePercent`, `highestScorePercent`, `lowestScorePercent`, `distribution` | 非课时任务、全班成绩未就绪 |

其他响应 record 无 `required` 且 nullable 字段，不改变其序列化策略。`Student.lastActivityAt` 在当前 ACTIVE 报名查询中通常由报名时间兜底；HTTP 测试核对键存在，未伪造不可达的空值。九个接口的 `period.dataThrough` 都核对键存在；无发布版本的五个可读取接口另核对显式 null。

## 数据、环境与启动

未创建或修改持久数据库、表、迁移、事件、环境变量或伪数据。自动化使用现有专用内存 H2 `t12c1_analytics_test`：测试启动时由既有 Flyway 迁移建表，单例测试创建固定伪 UUID 的课程发布事实、ACTIVE 学生、非视频课时和正式任务；每例使用 `@Transactional` 回滚，测试进程结束后内存库消失。重新运行同一测试即可重建，无需手工清理。未连接本地 MySQL、Redis、RabbitMQ 或 OSS。`local.env` 没有本任务新增配置，因此无需删除或迁移条目。

启动方式沿用 [本地环境说明](../development/local-environment.md)：需要本地凭据时经 `scripts/Invoke-WithLocalEnvironment.ps1` 启动既有服务。本任务无新启动参数。

## 可读性、风险与后续

人工检查本次修改的六个 record 中文 Javadoc 与 HTTP 测试注释：它们说明字段输出目的、空值来源和成绩门禁关系；没有修改自动生成代码。风险是未来新增教师学情 nullable 必需字段时，需在相应 DTO 保留显式 null 并扩展 HTTP 断言。本次修复不改变数据查询或权限结果。
