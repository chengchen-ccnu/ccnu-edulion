公告只允许 owner 教师在已发布、非暂停课程发布/修改/撤回。标题与纯文本保留换行，普通链接也是文本；无附件、Markdown、HTML渲染或定时发布。公共 Course 响应没有公告正文；当前 ACTIVE 报名者从独立受保护接口读取，游客/试看/退课者安全404，Gateway未登录401、缺能力403。课程暂停同样不授权正文。后报名者可读有效旧公告，无旧消息或置顶提醒。owner不作为学生收件人。

## 架构与可靠性

Gateway精确公告路由先于公共Course路由，重写可信身份头；Operation拥有公告、审计、确认、命令、消息与投递事实。Operation通过固定 `operation-service` caller/独立强秘密读取Course/Learning/IAM最小事实，不获取正文、资质材料、完整驳回理由或撤权原因，也不取得暂停写权限。正式业务无跨Schema查询/Join/外键或第二套消息系统。

Learning在报名/重报/退课同事务维护半开有效区间 `[startsAt, endsAt)`，触发时点有界查询每页最多100个learnerId，投递重新批量校验当前ACTIVE；owner排除。后报名及退课期间改版后重报不能混入旧提醒。迁移仅回填部署时最后已知区间，不重构历史多次重报，也不重放部署前消息。

HOMEWORK/EXAM开放工作持久化：`max(publishedAt, opensAt)`到达且课程/任务可访问才产生OPENED；空opensAt取发布时点。发布未来任务只登记工作。课程→测评锁与原CourseTaskClock一致，暂停停止触发、不消耗故障预算，恢复先按原暂停区间顺延再计算开放时点。教师最终截止变更/立即结束写事实与新事件同事务；PRACTICE、公共题库和Agent练习没有任务通知。重试再读取当前可作答状态，结束/暂停时抑制误导OPENED。

Operation Outbox与公告事实同事务，mandatory、相关发布确认ACK且没有return才PUBLISHED，默认最多20次、指数退避，FAILED不自动重放。独立 `edu.operation.notifications.v1` 队列绑定四类消息事件，消费总共三次尝试后进入其独立DLQ。完整eventId信封先严格校验字段/版本/UUID/动作，不允许隐私字段进入台账；同eventId异载荷拒绝，正常重复不重复创建工作。

投递工作每事务最多100人，消息与游标原子提交，工作行锁支持多实例竞争；重启从已提交游标继续。每页依赖故障最多5次，成功页重置页预算，耗尽保留FAILED而不无限重试。每轮最多10个工作页，任务开放每轮最多10场。消息列表、未读、目标和已读共用实时授权：本域快照按不变ID分批、每次领域请求最多100项，按时间/id降序展示，不因并发改版的排序移动而漏计；依赖失败503不能假零/假成功。普通目标GET不自动已读，实际目标成功加载后POST read；read-all跳过所有公告并返回剩余待确认数量。

## HTTP接口

| API | 结果与副作用 |
|---|---|
| GET/POST `/api/v1/teacher/courses/{courseId}/announcements` | owner分页/创建，创建写审计与Outbox |
| PUT `.../{announcementId}` | expectedRevision改版并重置已有消息 |
| POST `.../{announcementId}/withdraw` | 精确版本撤回，学生链接立即失效 |
| GET `.../{announcementId}/revisions` | owner不可变版本分页，无学生阅读名单 |
| GET `/api/v1/courses/{courseId}/announcements` | ACTIVE学生有效公告及最新未确认/剩余摘要 |
| GET `.../{announcementId}` | 最新正文，读取不确认 |
| POST `.../{announcementId}/confirm` | clientRequestId/expectedRevision确认与清对应未读 |
| GET `/api/v1/notifications`、`/unread-count` | 本人授权列表/两种真实数量 |
| POST `/api/v1/notifications/read-all` | 只清普通消息，返回剩余数量 |
| GET `/api/v1/notifications/{notificationId}/target` | 重新授权固定页面目标，暂停只返回状态/支持邮箱 |
| POST `.../{notificationId}/read` | 授权目标成功加载后的普通已读，公告409 |

外部字段唯一来源是OpenAPI；所有写命令使用UUID请求ID和版本。错误仍含code/message/traceId/timestamp/path/fieldErrors。内部协议提供Course最多100个最小事实、Learning历史名单/当前名单/目标与历史资格、IAM本人申请目标；不经Gateway公开。
