# T12F.2 课程内容与播放器前端

## 目标与边界

本任务只扩展既有教师课程编排页 `/teacher/courses/:courseId/curriculum` 和学生课程学习页 `/learn/:courseId/:lessonId`。实现消费 OpenAPI 0.19.1 生成客户端，不修改 OpenAPI、Java 业务契约、Flyway 或事件 Schema，也没有增加平行路由、第二套 OSS 客户端、字幕 UI、多码率、清晰度选择、Office 在线转换、历史海报生产重处理、DRM、AI 或 T12G Redis 缓冲。

教师端增加 ARTICLE Markdown 编辑、工具栏、实时预览、正文图片和学习资料编排；学生端从受保护课时内容接口读取正文、资源、视频和海报，正文成功渲染后有限重试写入图文完成事实；共享播放器增加自定义/自动/固定占位海报和 1～3 倍速。教师预览与学生正文均复用同一 Markdown、KaTeX 与 DOMPurify 安全流水线。

## 主要实现与调用流程

### 共享 Markdown 与资料动作

- `render-article-markdown.ts` 使用 marked 的 GFM 表格/代码能力，将行内与块级公式交给 KaTeX，并在最终输出阶段统一执行 DOMPurify。正文图片只接受 `media:<UUID>` 引用；原始 HTML 图片、外部图片、非 HTTPS 链接和危险协议不会进入结果。
- `SafeArticleContent.vue` 逐个调用课程域提供的正文图片授权函数，把短期授权内容下载为内存 Blob URL。只有 Markdown 和全部正文图片均成功后才发出 `rendered`；失败发出 `renderError`，离页或输入变化时中止请求并回收 Blob URL。
- `resource-actions.ts` 每次预览/下载都重新申请课程域授权，再生成短期 Blob URL；不缓存签名 URL、Object Key 或 Bucket。控制器离页时中止请求、清理定时器并回收 URL。PDF/普通图片允许 PREVIEW 和契约允许的 DOWNLOAD，PPTX/TXT 只显示 DOWNLOAD，ARTICLE_IMAGE 不作为独立资料展示。

### 教师课程编排

- ARTICLE 使用 Markdown 编辑区、标题/列表/表格/LaTeX/代码/HTTPS 链接/正文图片工具栏和共享实时预览。正文图片复用 `MediaUploadField` 与 media-service 上传会话，purpose 为 `ARTICLE_IMAGE`，只有 READY 后才插入 `media:<mediaId>`。
- 课程资源保留生成类型中的 `displayName`、`presentation` 和不可变文件快照；保存时仅提交正文仍引用的 ARTICLE_IMAGE，因此删除最后一个引用后不会继续绑定该资产。
- 已保存 ARTICLE 重新进入或硬刷新时调用生成客户端的 `GET /api/v1/teacher/courses/{courseId}/lessons/{lessonId}/article-content`，使用返回的 `articleMarkdown` 和 `inlineImages` 短期授权渲染正文图片。图片授权返回 401/403 时只通过同一接口刷新一次，不缓存永久 URL 或拼接 OSS 地址；新上传未保存图片继续使用当前页面 Blob 预览。
- 草稿仍为显式保存，携带 `expectedRevision`；409、422、429、离线/5xx 均保留输入并显示对应提示。`beforeunload` 和路由离开守卫覆盖未保存提示，没有自动保存状态机。
- VIDEO、ARTICLE、ASSESSMENT 类型互转先二次确认；取消时恢复原选择并保留未保存输入，确认后才清理不兼容绑定。既有 SUBTITLE 数据在兼容 VIDEO 编辑中保留，但页面没有字幕按钮、菜单、面板或上传入口。

### 学生学习与播放器

- 公共 `CourseDetail` 只恢复目录；正文、`playbackResourceId`、海报和资源绑定全部来自受保护 `GET /api/v1/courses/{courseId}/lessons/{lessonId}/content`。
- ARTICLE 只有在共享安全渲染器和全部正文图成功后才调用 `POST /api/v1/learning/courses/{courseId}/lessons/{lessonId}/article-completion`。每次打开创建一个 UUID，在页面存活期间复用；现有授权请求适配器最多退避重试三次，失败显示“正文可继续阅读，完成状态尚未同步”，离页中止且不再重试。未报名付费试看只读，不写完成。
- `HlsVideoPlayer` 优先使用课程域返回的有效自定义海报或自动 `poster-v1`，缺失时显示统一 SVG 占位。倍速为 1、1.25、1.5、2、2.5、3，设置 `preservesPitch`；倍速只在组件实例内存在，切课、刷新和重新进入均恢复 1x，不写 Web Storage。
- 页面和共享组件对 401、403、404、409、422、429、离线/5xx、loading、empty、partial-error 提供有限失败语义；离页销毁 HLS、AbortController、进度定时器、资源授权和临时 URL。

## API、数据库与环境

本任务消费以下 OpenAPI 0.19.1 生成路径和 Schema：教师已保存 ARTICLE 正文投影、受保护课时内容、教师/学生资源动作授权、ARTICLE 完成、既有教师草稿更新、课程域播放授权及 media-service 上传会话。`packages/api-client/src/index.ts` 只导出 `components["schemas"]` 的别名，没有手写 DTO。教师正文投影只由课程域按当前 owner、当前可编辑版本、已保存 Markdown 引用和同课时唯一 `ARTICLE_IMAGE` 绑定返回；前端不接受浏览器提交的任意 `mediaId`，也不把正文图片加入普通资料动作。

没有新增或修改 API、数据库表、迁移、事件或环境变量。真实验收复用专用 `edu_platform_iam_dev`、`edu_platform_course_dev`、`edu_platform_media_dev`、`edu_platform_learning_dev` 以及 T12F.1 固定 Seed；未创建随机课程或历史海报补丁。服务通过 `scripts/Invoke-WithLocalEnvironment.ps1` 注入仓库外加密凭据启动。当前本地初始化文件把 Gateway 与 IAM 分别放在 Redis DB 0/1，验收进程临时把 Gateway 对齐到 IAM DB 1 才能通过登录后的 session-version 校验；这项进程覆盖未提交为后端改动。补验还修复了 T12D.1 遗留 Cookie 迁移：登录、验证码登录、刷新成功和退出响应在维护当前 `/api/v1` Cookie 的同时清除旧 `/api/v1/auth` Path Cookie，避免浏览器同时发送两个同名值；该修复不改变 OpenAPI 字段或令牌业务语义。

## 人工演示步骤

1. 启动五个 Java 服务和 student/teacher Web，确认 Gateway 与 IAM 的 session-version 使用同一 Redis DB。
2. 使用固定学生身份登录，深链接进入课程 `...f201` 的 ARTICLE 课时 `...f232`，观察 Markdown、公式、表格、代码和正文图片；核对 PDF、TXT、PPTX 的动作差异和图文 0%→100%。
3. 切到视频课时 `...f231`，确认海报、六档倍速、保持音调；选择 3x 后切课或重建播放器，确认恢复 1x 且无字幕 UI。
4. 使用固定教师身份进入既有课程编排页，核对 ARTICLE 工具栏、正文/公式/表格/代码实时预览、正文图上传、资料展示名/呈现方式、显式保存与类型互转取消保留输入。刷新或重新进入已保存 ARTICLE 后，页面必须通过 `article-content` 投影读取正文和短期图片授权；新上传未保存图片仍可本地预览。
5. 在移动端、平板和桌面尺寸验证布局、键盘焦点、深链接和硬刷新；结束后执行 Rebuild/Initialize 并核验进度为 0%。
