# T14.3 公共题库自主组题 Skill 与确认契约

日期：2026-09-13。状态：实现、自动化与真实环境验收完成；[Ready PR #68](https://github.com/chengchen-ccnu/ccnu-edulion/pull/68) 已创建，本任务不合并。

## 目标与功能边界

本任务把“想练某主题”闭合为可恢复的候选、确认和本人自主练习。Python 平台运行时 Skill `public-practice-generation@1.0.0` 只解析主题、难度和 1～20 道主问题数量，并从既有 Qdrant 公共题索引提出稳定题目/版本身份；Agent Access 保存并治理待确认动作；Learning 独占当前题目事实校验、练习创建、作答和评分。

默认难度为 `MEDIUM`、默认 5 道。组合题按一个主问题计数且完整保留子题，套内去重并软避开近期题；可靠候选不足时返回真实数量，不放宽到教师私题、其他学段或错误难度。主题缺失时澄清；参数实质变化使旧动作失效。模型临时例题不会写入题库或练习，Agent 不能替学生保存、提交或评分。

没有新增 Vue 页面、导航或第二套答题器；T15C 负责在既有 AI 页面/悬浮窗消费本任务的生成客户端与结果卡片。

## 架构与调用流程

1. Practice Coach 识别 `RECOMMEND_PRACTICE`，当前显式主题优先，随后才使用可信当前子请求、会话或最近明确主题。Skill 以固定描述符和工具白名单查询现有混合索引，最多保留 20 个安全候选身份。
2. Python 在最终事件中报告建议；Agent Access 不直接信任该报告，调用 Learning 校验题目仍为 `ACTIVE SYSTEM`、初中数学、当前根版本、指定难度及自动评分题型。只有复核后的候选会写入 `ai_pending_action`，同会话只保留一个 `PENDING` 动作。
3. 学生可显式确认/取消。`好的` 等自然确认只在唯一明确待确认动作时生效；动作默认 10 分钟过期。确认前 Agent Access 再次复核候选，以 CAS 抢占 `EXECUTING`，并以稳定 `sourceActionId` 请求 Learning。
4. Learning 在单个事务中创建无课程、无教师、无倒计时的 `PUBLISHED PRACTICE`、不可变题目快照和 `autonomous_practice` 映射。唯一约束保证一个动作只生成一次 assessment；相同请求、并发确认和远端已提交但响应丢失均查询并返回同一结果。
5. 本人通过稳定入口进入既有 attempt 保存/提交链路。自主练习提交时自动评分并公开答案；不进入课程任务、教师课程归属、成绩册或课程错题统计。非 owner 统一不可见。

## 外部与内部契约

- `docs/api/openapi.yaml` 从 0.23.3 升级到 0.23.4：新增当前会话动作查询、按 action 查询、确认、取消和自主练习入口；读取同样携带 `requestId`，便于超时后的稳定追踪。
- `PendingPracticeAction` 只公开主题、难度、请求/实际数量、候选稳定 ID/类型/难度、状态、revision、过期时间和成功入口；不含题干、答案、解析、提示词、Token、签名 URL或内部异常。
- SSE `FINAL_RESULT` 可选返回由 Java 复核并持久化后的 `pendingPracticeAction`，Python 原始候选不会直接透传浏览器。
- `docs/api/agent-internal.yaml` 从 1.2.0 升级到 1.3.0：新增运行时 Skill 描述符、建议报告，以及 Agent Access↔Learning 的候选复核、幂等创建和结果查询契约。
- `web-apps/packages/api-client/src/generated/schema.d.ts` 已由同一 OpenAPI 重新生成，没有手写平行 DTO。

## 数据库与迁移

- Agent Access `V6__create_pending_practice_action.sql` 新增 `ai_pending_action` 和 `ai_pending_action_audit`。唯一 pending slot、source run、revision/CAS、请求 ID和审计记录共同覆盖替换、重复确认、取消、过期、并发和恢复；候选 JSON 只保存稳定身份与安全元数据。
- Learning `V16__add_autonomous_practice_ownership.sql` 为 assessment 增加 `ownership_type`，保持旧 `COURSE` 行的教师/课程非空约束，并允许严格限定的 `AUTONOMOUS PRACTICE`；新增 `autonomous_practice`，对 source action 和 assessment 分别唯一。
- 迁移只向前演进，没有修改历史迁移，没有跨 Schema 外键、Join 或共享 Mapper。

真实验收只使用既有、用途明确的 `edu_platform_agent_dev` 与 `edu_platform_learning_dev`，未创建数据库、账号、课程、题目、媒体、Seed 或永久伪数据。验收临时创建会话、run、动作、自主练习、attempt 和 Redis 运行事实；脚本按本轮随机 owner/conversation/action 精确清理，最终 `learningRemaining=0`、`agentRemaining=0`、`redisRemaining=0`。重复执行会使用全新随机标识，不产生累计数据。

## 人工演示

1. 以有 `learning:access` 的测试学生打开独立 AI 页面或公共题悬浮会话，发送“给我出 5 道一元一次方程中等题”。
2. 确认返回待确认动作，展示请求数量与真实可用数量、难度和过期状态，但不展示答案或自动创建练习。
3. 回复明确确认或调用确认端点；重复提交相同 `requestId`，确认 action、assessment 与开始路径保持不变。修改难度/数量后确认旧动作已失效。
4. 打开返回的 `/practice/assessments/{assessmentId}`，保存并提交；确认提交前不显示答案，提交后显示自动评分与答案。换用另一学生访问应返回不可见。
5. 可运行上述真实验收脚本自动复现超时恢复、并发和精确清理场景。

## 可读性、风险与后续

新增 Skill、状态转换、跨服务调用、事务创建、权限判断和复杂测试均补充通俗中文 docstring/Javadoc/SQL 注释；生成客户端没有手工补注释。人工检查确认 Python 不写 MySQL，Agent Access 不查 Learning 表，Learning 不信任索引作为最终事实，日志/响应不包含秘密或题目答案。

已知风险：公共题当前真实主题在严格难度、题型和阈值下可能不足请求数，这是预期的真实不足语义；T15C 需要呈现修改条件、过期和 `EXECUTING`/未知结果查询状态。跨服务确认不是分布式事务，可靠性依靠稳定 action ID、Learning 唯一约束和查询恢复；部署监控仍需关注长时间 `EXECUTING` 动作。
