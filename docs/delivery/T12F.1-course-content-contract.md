# T12F.1 课程内容、资源授权与自动海报后端契约

## 目标与边界

本任务以 OpenAPI 为先，把外部契约从 0.18.0 向前演进到 0.19.0，再落地 Course V4、Media V5、Learning V12 和生成 TypeScript 客户端。交付包括受控 ARTICLE Markdown、`ARTICLE_IMAGE`、课程版本资源快照、登录后的课时内容投影、由课程域决定的资源动作授权、新视频自动 `poster-v1`、ARTICLE 0→100 幂等完成命令，以及生产禁用的跨域演示数据编排。

本任务没有实现 Vue 业务页面。学生/教师现有 TypeScript 只做生成契约的可选字段兼容，未增加路由、按钮或占位功能。多码率、清晰度、字幕访问/UI、历史视频重处理 API、Office 在线转换、DRM、AI、T12G Redis 播放进度和第二套 OSS 客户端均明确排除；存量 `SUBTITLE` 上传枚举和 READY 绑定校验保留。

## 契约与调用流程

公开 `CourseDetail` 只保留课程决策信息：`LessonSummary.resources` 已标记 deprecated/optional，公共响应不再序列化资源行或 `articleMarkdown`，`coverMediaId` 同样转为 deprecated/optional。教师当前草稿投影继续返回完整 Markdown、资源行 ID、mediaId 和不可变安全快照，供 T12F.2 编辑器消费。

受保护读取链路如下：

1. 浏览器携带登录身份请求当前发布课时内容；试看也必须登录。
2. course-service 只解析当前不可变发布版本，按 PUBLIC、有效报名或 `previewable` 判断可见性；草稿、历史版本、错课程/课时统一不可见。
3. course-service 从自己的资源行解析 mediaId、用途、`ORIGINAL`/`poster-v1` 变体和 INLINE/ATTACHMENT，再签发短时一次性服务令牌给 media-service。
4. media-service 独立复核用途、READY、允许的访问类型和令牌重放，返回不含 Bucket/Object Key/永久 URL 的短期 GET 投影。

教师资源预览使用相同链路，但只允许当前教师拥有的可编辑版本。PDF 和普通附件图片允许 PREVIEW/DOWNLOAD，PPTX/TXT 只允许 DOWNLOAD；ARTICLE_IMAGE 只随受保护正文投影以内联授权返回，浏览器不能凭 mediaId 申请。

新增或扩展的 API：

- `GET /api/v1/courses/{courseId}/lessons/{lessonId}/content`：返回受控正文、课程域视频资源行 ID、有效自定义/自动海报、正文图短期授权和安全附件投影。
- `POST /api/v1/courses/{courseId}/lessons/{lessonId}/resources/{resourceId}/access-grants`：按 PREVIEW/DOWNLOAD 申请已发布资源。
- `POST /api/v1/teacher/courses/{courseId}/lessons/{lessonId}/resources/{resourceId}/access-grants`：教师 owner 的草稿资源授权。
- `POST /api/v1/learning/courses/{courseId}/lessons/{lessonId}/article-completion`：使用稳定 `clientRequestId` 把 ARTICLE 完成事实从 0 单调推进到 100。
- 课程创建/编排、Media binding validation 和 Media 查询向前增加 Markdown、展示字段、安全快照、派生变体名称与处理契约版本；binding validation 不返回存储定位信息。

## Course V4

`lesson.article_markdown` 保存 ARTICLE 源 Markdown。服务端按可见字符而非原始字节限制 100,000 字，允许标题、列表、表格、代码、HTTPS 链接、LaTeX 和固定 `![必填替代文字](media:UUID)`，拒绝原始 HTML/iframe、外部图片、data URL、危险协议和格式错误的媒体占位符。危险内容即使伪装在 VIDEO/ASSESSMENT 请求中也在丢弃前立即拒绝。

同一正文图片在一课时只允许一个资源绑定，正文可重复引用；保存时引用 UUID 集合必须和 ARTICLE_IMAGE 绑定集合完全一致。所有绑定都会立即向 media-service 校验 owner、精确用途和 READY，并冻结原始文件名、MIME、大小、教师 `displayName` 与 `presentation`。空白 displayName 使用绑定时文件名；ARTICLE_IMAGE 固定 INLINE，PPTX/TXT 固定 DOWNLOAD，不安全的显式组合直接返回 422。

草稿允许空 ARTICLE 和无视频 VIDEO。发布时 ARTICLE 必须有非空合法正文，VIDEO 必须有 READY 视频；新 `LESSON_VIDEO_V5` 还必须冻结到 `hls-fmp4-v2` 与 `poster-v1`。所有已绑定资源必须 READY。已发布版本不原地修改，后续编辑复制到新草稿版本。

类型切换按最终请求释放不兼容绑定：VIDEO→ARTICLE 释放视频/海报/字幕，ARTICLE→VIDEO 释放正文图/ARTICLE_ATTACHMENT，ASSESSMENT 互转同样清除不兼容内容；COURSEWARE 可保留并复用原资源行。解除事件与课程写事务共同写 `MediaReferenceReleased` Outbox，避免先发消息或跨库事务。

## Media V5

`ARTICLE_IMAGE` 只允许教师上传 JPG/JPEG、PNG、WebP，最大 10 MiB，固定单对象直传；SVG、GIF 和 Multipart 均拒绝。新上传 LESSON_VIDEO 写入 `LESSON_VIDEO_V5`，同一有限重试处理作业生成现有单清晰度 fMP4 HLS 与 `poster-v1`，二者均成功才 READY；处理耗尽进入 FAILED。

自动海报用 ffprobe 在视频前 30% 收集最多 12 个关键帧，逐帧跳过近乎纯黑/纯白画面，无合格候选时回退视频 10% 位置。输出使用 WebP/libwebp quality 85，保持比例、最长边不超过 1280 且不上采样。`poster-v1` 是原视频派生变体并随原件回收；独立 `VIDEO_POSTER` 仍是教师自定义覆盖。历史视频的处理契约为 null，不触发批量或暗中重处理。

## Learning V12

ARTICLE 完成事实和 `clientRequestId` 映射使用独立表，不写伪造的视频 positionSeconds/watchedSeconds 事件。事实由 learner/course/lesson 唯一约束保证只创建一次；相同请求重放返回同一事实且标记 replayed，不增加 revision，不同业务目标复用同一请求 ID 返回 409。只允许 PUBLIC 或 ACTIVE 报名用户记录；未报名付费试看可读正文但返回 `LEARNING.ENROLLMENT_REQUIRED`，普通客户端没有回退接口。

T12F.2 应在正文成功渲染后调用，单次页面存活最多重试三次且复用同一请求 ID；失败不阻塞正文，下次打开可创建新的逻辑请求。这一页面策略仅在契约中冻结，本任务不实现 Vue。

## 数据库与迁移

- Course V4 `V4__add_lesson_content_contract.sql`：为 lesson 增加 `article_markdown`；为资源绑定增加 display/presentation/文件名/MIME/大小/安全变体名/处理契约，并向前扩展用途 CHECK。
- Media V5 `V5__add_course_content_media_contract.sql`：为 `media_asset` 增加可空 `processing_contract_version`；空值明确表示历史资产。
- Learning V12 `V12__add_article_lesson_completion.sql`：新增 `article_lesson_completion` 和 `article_completion_request`，以唯一事实和请求主键实现单调幂等。

迁移已在现有专用 `edu_platform_course_dev`、`edu_platform_media_dev`、`edu_platform_learning_dev` 上由 Flyway 正常向前应用。没有创建数据库，没有改写已合并迁移，没有跨 Schema 外键、Join 或事务。保留的持久变化只有三个开发 Schema 的 V4/V5/V12 表结构和 Flyway 历史。

## 环境、启动与演示数据

服务仍通过 `scripts/Invoke-WithLocalEnvironment.ps1` 注入 MySQL、课程/媒体服务授权和既有本地配置。T12F.1 没有新增仓库内秘密；Media 需要现有 `OSS_ENDPOINT`、`OSS_REGION`、`OSS_BUCKET`、访问凭据及 `ffmpeg`/`ffprobe`，真实 RabbitMQ 使用现有 Spring AMQP 配置。

演示编排：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Invoke-T12F1CourseContentDemoSeed.ps1 -Action Initialize
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Invoke-T12F1CourseContentDemoSeed.ps1 -Action Cleanup
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Invoke-T12F1CourseContentDemoSeed.ps1 -Action Rebuild
```

固定演示资源由各域独立拥有：Media 资产 `...f101`～`...f106` 和精确前缀 `t12f1-demo/...`；Course `...f201`、视频课时 `...f231`、图文课时 `...f232`；Learning 学习者 `...0101` 的图文进度行 `...f401`。内容包含 2 秒音视频、自动/自定义 WebP 海报、正文 PNG、可解析的最小 PDF/PPTX 和 TXT；图文包含公式、表格、代码和正文图片，占位符 alt 非空。二进制只在临时目录生成，不进入 Git。

Initialize 在完整存在时只校验，部分存在拒绝覆盖；Cleanup 按 Learning→Course→Media 逆序删除固定请求/完成事实/进度、课程子表/Outbox、数据库记录所指向的原件和派生 Object Key，不列举 Bucket；Rebuild 先 Cleanup 再 Initialize，并恢复 0% 图文进度。普通构建不会设置门控变量，production 不会自动初始化。

本机实际运行时，三个开发 Schema 已完成迁移，但共享配置中 `OSS_ENDPOINT`、`OSS_REGION`、`OSS_BUCKET` 为空。编排脚本现在会在修改任何域之前统一检查这些值并安全失败；此前尝试中已逆序清掉可能的固定课程/学习记录，媒体初始化未发生。当前没有保留 T12F.1 演示 Seed、OSS 对象或临时文件。补齐明确的开发 Bucket 后执行 Rebuild 即可创建所述保留数据；演示结束若不需保留则执行 Cleanup。

## 人工演示步骤

1. 补齐明确开发 OSS 配置并执行 Demo `Rebuild`，确认三个 Seed 测试各自只连接对应 dev Schema。
2. 启动 Media→Course→Learning→Gateway；以测试教师读取固定课程草稿，确认 ARTICLE 原始 Markdown、六个资源快照和自定义海报绑定。
3. 匿名读取公共 CourseDetail，确认正文、资源行、mediaId 均不存在；登录学生读取两个课时的 protected content，确认图文占位符有匹配的临时内联图授权，视频优先返回自定义海报。
4. 对 PDF 分别申请 PREVIEW/DOWNLOAD，对 TXT/PPTX 只申请 DOWNLOAD；验证错误动作 422、错 resourceId/lessonId 404、未报名非试看 403，响应与日志无 Object Key/Bucket。
5. 以稳定 `clientRequestId` 连续两次提交 ARTICLE 完成，确认只有一个完成事实、第二次 replayed=true、进度为 100%；Rebuild 后重新核对为 0%。
6. 不需长期保留演示数据时执行 Demo `Cleanup`，复核固定数据库 ID、精确 OSS Key、派生变体、消息和本机临时文件均不存在。

## 可读性、风险与后续

新增业务类、公共方法、权限判断、状态机、幂等/补偿、Seed 和复杂测试均补充了说明输入、输出、写入和失败语义的中文 Javadoc/注释；OpenAPI 与迁移对兼容字段、历史资产空值和存储信息禁区有内联说明。自动生成的 `schema.d.ts` 未手工补注释。

已知风险是本机缺少完整 OSS 非敏感定位配置，故真实 OSS 综合链路与保留 Demo Seed 尚待复验；这是显式记录的外部环境缺口。历史 READY 视频继续没有 poster-v1，不会被自动批量修改；T12F.2 需按 ADR 使用固定占位或正常上传自定义 VIDEO_POSTER。内容安全当前是 Markdown 结构/协议白名单和媒体 MIME/大小策略，不等同病毒或恶意文档扫描。

后续 T12F.2 只能消费 0.19.0 生成客户端，在既有课程编排与 `/learn/:courseId/:lessonId` 实现页面和最多三次完成重试，不得扩大本任务排除项。
