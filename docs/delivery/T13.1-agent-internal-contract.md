# T13.1 Agent 内部协议与工具契约交付

日期：2026-09-09。状态：实现与本地契约验证完成，Ready PR #56 的最新 CI 全绿，未合并。

## 1. 目标与范围

本任务只冻结 Java `agent-access-service` 与 Python `edu_agent_app` 之间的内部协议、受控工具契约和派生索引事件，不实现动态多 Agent 运行时。首期范围固定为学生初中数学答疑、数学学习方法和平台数学学习帮助能力位置。

已明确排除：旧固定认知诊断、固定解题图、人工教师转交、旧 FAISS 新方案依赖、Java Agent Access 服务、数据库表、Redis 状态、真实 RabbitMQ、Qdrant、Neo4j、Index Worker、模型调用和 Vue 页面。浏览器外部 [`openapi.yaml`](../api/openapi.yaml) 没有修改。

## 2. 协议版本与调用流程

内部协议唯一事实源为 [`agent-internal.yaml`](../api/agent-internal.yaml)，OpenAPI 3.1，协议版本 `1.0.0`，服务间头版本为 `1`。

调用链为：浏览器后续经外部 API 发起逻辑请求 → Java 保存消息/run 并完成身份与领域授权 → Java 以 v1 可信上下文调用 Python → Python 返回有类型 SSE → Java 保存安全事件/检查点并代理给浏览器。恢复页面只读取已保存结果，不自动重新生成。

内部端点：

- `POST /internal/v1/agent/runs`：创建或找回同一次 run，并返回 UTF-8 SSE。
- `POST /internal/v1/agent/runs/{runId}/cancel`：按 `runId + cancelRequestId` 幂等取消。

身份职责：`conversationId` 是会话，`messageId` 是已保存的用户消息，`runId` 是一次执行，`clientRequestId` 是一次逻辑发送，`traceId` 只用于安全追踪。`conversationId + clientRequestId` 不得创建第二条消息，`messageId + runId` 重试不得启动第二次执行；重新生成必须显式使用新 runId。同会话最多一个活动 run，冲突为可重试 `409/AGENT.RUN_CONFLICT`，不后台排队。

## 3. 可信上下文与私有状态

`TrustedContext` 只允许 Java 已授权的全局 userId、初中年级、入口、明确偏好、题目版本安全投影、课程/课时范围、学生主动附加的 `STUDENT_DRAFT`、本人学习事实引用、媒体引用、记忆摘要和工具授权。浏览器角色、权限或任意资源 ID 没有对应字段，不能被直接提升为事实。

短期媒体 URL 若由 Java 提供，标记为 `SHORT_LIVED_SECRET`/`writeOnly`，只供受控读取适配器使用；不得回显、持久化、记录日志、进入来源、传给模型或出现在工具结果。Python 不接 OSS SDK，也不接受浏览器任意 `image_url`。

Python 私有路由、提示词、推理、工具原始结果和内部工作集不定义为 HTTP DTO；请求和流中禁止 `privateState`、`hiddenProfile`、`systemPrompt`、`chainOfThought`、`rawToolResult`。

## 4. 流式事件与终态

流事件有稳定 runId、从 1 开始连续递增的 sequence、traceId、时间和可判别 payload：

- `RUN_ACCEPTED`
- `STAGE_CHANGED`
- `TEXT_DELTA`
- `CLARIFICATION_REQUIRED`
- `REFERENCE`
- `PARTIAL_CHECKPOINT`
- `HEARTBEAT`
- `RUN_ERROR`
- `FINAL_RESULT`

每个 run 恰有一个、且最后一个事件必须是 `FINAL_RESULT`。终态为 `COMPLETED`、`DEGRADED`、`LIMIT_REACHED`、`CANCELLED`、`FAILED`。取消/断线后不得开始新模型或工具调用。已保存片段使用 `INTERRUPTED` 和固定提示“回答已中断”，不能伪装为完整答案或掌握证据。

首事件超时、空闲超时和慢客户端缓冲溢出映射到安全错误及 `FAILED`；总时限用尽映射到 `LIMIT_REACHED`，尽量返回已有可靠简化内容。`RUN_ERROR` 不是第二个终态，之后仍以唯一 `FINAL_RESULT` 收口。

## 5. 意图、角色和工具白名单

一级意图固定为数学辅导、练习辅导、学习规划、平台帮助、普通对话、不支持请求和动作控制；二级意图完整覆盖任务要求的 14 个值。角色固定为 Coordinator、Math Tutor、Practice Coach、Study Planner、Platform Help（协议枚举使用大写下划线）。一级意图选择专家，二级意图限制槽位和允许工具；一次最多两个有序子请求，缺少关键槽位时返回澄清。

Platform Help 的正式知识库仍属于 T13.4；本任务只保留 `USER_HELP_SEARCH` 位置和明确不可用结果。

只读工具白名单：

- `QUESTION_SEARCH`：公共题与题目安全投影。
- `KNOWLEDGE_SEARCH`：数学知识点。
- `PREREQUISITE_GRAPH`：Neo4j 有界前置/后续关系位置。
- `STUDENT_WRONG_QUESTIONS`、`STUDENT_SUBMISSIONS`、`STUDENT_PUBLISHED_GRADES`、`STUDENT_PROGRESS`：学生本人事实。
- `COURSE_TEXT_SEARCH`：Java 授权课程文字；权限依赖失败不退化为全库检索。
- `AUTHORIZED_IMAGE_UNDERSTANDING`：已授权题图/图片理解。
- `USER_HELP_SEARCH`：T13.4 用户帮助知识库位置。

每次调用必须有 `toolCallId`、runId、traceId 和 100～30000ms 超时，并同时匹配 Java 下发的工具名与资源范围。结果状态为 `SUCCEEDED/EMPTY/REJECTED/TIMEOUT/FAILED`，只允许安全证据摘要；未公布答案/解析/成绩、教师私题、Token、签名 URL、提示词、内部推理和原始工具结果无法通过 Schema。所有业务写工具保持禁用，自主组题确认留给 T14.3。

## 6. 预算与有限循环

预算字段由 Java 配置后逐 run 下发，Schema 的 `default` 是首版建议，不是不可修改的产品常量：12 个编排步骤、8 次 LLM（其中 1 次预留最终降级）、10 次工具尝试、2 次专家转交、同工具同参数最多 2 次、总时限约 90 秒。教学补救最多依次执行“换一种表述 → 简单例子 → 回退前置知识”。

失败重试、视觉、总结和记忆提取都计入预算。达到上限后用已有可靠信息给出简化回答，以 `DEGRADED` 或 `LIMIT_REACHED` 收口；不转人工、不无限循环。

## 7. 索引事件

[`agent-index-events.v1.yaml`](../events/agent-index-events.v1.yaml) 沿用仓库统一信封、Outbox、at-least-once、有限重试/DLQ 和 `eventId` 幂等语义，定义四类通知：

- `QuestionIndexProjectionChanged`
- `KnowledgePointIndexProjectionChanged`
- `CourseTextIndexProjectionChanged`
- `StudentMemoryIndexProjectionChanged`（为 T14.2 保留）

每类支持 `UPSERT/DELETE`，携带事实源、稳定实体 ID、`sourceRevision`、`JUNIOR`、可见范围和最小授权元数据。事件不复制题干、答案、课程正文、记忆正文、完整隐私、隐藏权限名单或签名 URL。消费者按 `eventId` no-op 去重，并按事件类型＋实体 ID 保存最高 revision；旧或相同 revision 不覆盖新投影，DELETE 形成同 revision tombstone。

真实事件生产、RabbitMQ 资源、Qdrant/Neo4j 消费、重建与对账分别依赖 T14.1、T13.2 和 T14.2。

## 9. 环境、数据与已知限制

没有新增运行环境变量、服务端口或启动模式。新增的 [`requirements-contract.txt`](../../requirements-contract.txt) 仅声明 `PyYAML>=6.0` 和 `jsonschema>=4.23` 两个契约测试依赖；CI 在纯单元测试前单独安装它们，不把测试库加入 Agent 运行时依赖。wheel 仍按 `--no-deps` 构建。

没有安装或连接 Qdrant、Neo4j、聊天/视觉模型、MySQL、Redis、RabbitMQ、OSS；没有创建或修改数据库、表、迁移、Seed、伪数据、缓存 Key、消息、媒体、向量 collection 或图节点，因此没有数据清理/重建操作。

已知限制：本任务只有协议与替身式契约测试，不证明网络背压、供应商取消、真实 SSE 代理、领域授权 API、消息投递、索引一致性或模型行为已经实现。T14.1 应实现 Java 会话/授权/流代理并用本协议替身验收；T13.2 实现索引 Worker 与真实 Qdrant/Neo4j；T13.3 实现动态五角色；T14.2 接入长期记忆与真实端到端状态；T13.4 才启用完整 Platform Help。
