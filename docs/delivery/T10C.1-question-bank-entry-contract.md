## 主要实现与调用流程

OpenAPI 0.22.0 是本次唯一外部契约源，生成客户端由 `pnpm.cmd --dir web-apps run generate:api` 更新，未手写前端 DTO。

1. 公共题：浏览器经 Gateway 携带 `learning:access` 调用既有列表/详情；Learning 只读取当前 ACTIVE SYSTEM 根题及冻结有序子题，并从题干/选项与答案/解析的稳定媒体占位中裁剪安全绑定。
2. 公共题媒体：浏览器把详情中可见的 mediaId 交给新增领域入口；Learning 重查当前根题/子题绑定、用途和处置方式，再签发一次性 `SYSTEM_QUESTION_CONTENT` 服务令牌；Media 校验 issuer、audience、subject、mediaId、purpose、variant、disposition、jti 与 READY 状态后返回短期 URL。通用媒体 grant 仅允许 uploader。
3. 课程练习：`GET /api/v1/learning/courses/{courseId}/tasks?type=PRACTICE` 先取得当前已发布 Course 事实并校验报名，再在 Learning SQL 中按 courseId、PUBLISHED、PRACTICE、匹配 COURSE assignment 筛选，最后复核 assessment owner 与当前课程 owner；筛选发生在分页前。
4. 旧链接：`GET /api/v1/learning/assessments/{assessmentId}/entry` 从持久 assessment 解析 courseId，再执行相同课程事实、报名、发布和 assignment 复核，只返回 `LearnerCourseTaskSummary`。关闭练习可安全解析归属，但不会返回题目或重新允许开始。
5. 旧 PRACTICE：列表、详情和 entry 的 GET 不创建 participant/attempt；仅合法的开始事务在开放检查后为本人补/恢复 participant，并继续复用原 PRACTICE 单次 attempt、草稿、提交和结果逻辑。

## API 与错误语义

- 复用 `GET /api/v1/learning/system-questions` 与 `/{questionId}`；要求 `learning:access`，答案、解析和答案专用媒体不存在于响应。
- 新增 `POST /api/v1/learning/system-questions/{questionId}/media/{mediaId}/access-grants`；只支持 ORIGINAL，QUESTION_IMAGE/QUESTION_AUDIO 为 INLINE，QUESTION_ATTACHMENT 为 ATTACHMENT。
- 扩展 `GET /api/v1/learning/courses/{courseId}/tasks` 的可选 `type`；省略保留 HOMEWORK/EXAM，`PRACTICE` 只返回指定课程练习。
- 新增 `GET /api/v1/learning/assessments/{assessmentId}/entry`，复用既有 `LearnerCourseTaskSummary`，不返回 questions/answers/analysis。
- 401/403/404/409/422/429/503 继续使用统一错误信封。枚举转换与方法级分页约束已补齐 422 适配，避免框架参数错误落入 500。

没有新增 DTO、表、迁移或事件；Gateway 已有 `/api/v1/learning/**` 路由，本次只增加能力回归测试。没有修改 Vue、Python Agent、评分算法、HOMEWORK/EXAM 公布规则或整场结果门禁。

## 人工演示步骤

1. 使用具备 `learning:access` 且已报名目标课程的测试账号，从公共题列表读取一页并进入一题；确认响应无 answers/analysis，组合子题顺序和可见图片 mediaId 正常。
2. 对详情中的可见 mediaId 调用公共题媒体授权并加载短期 URL；对答案专用、他题、历史版本或教师私题 mediaId 应为 404，错 disposition/variant 为 422。
3. 调用课程 tasks：省略 type 时只见 HOMEWORK/EXAM，传 `type=PRACTICE` 时只见该 courseId 的教师已发布练习；换成未报名账号、其他 courseId、未发布/未分配练习应分别得到 403 或安全 404。
4. 对旧 `/practice/:assessmentId`，先调用 entry 得到服务端授权的 courseId，再迁移到 `/learn/{courseId}/tasks/{assessmentId}`；关闭练习只显示安全摘要/最后结果入口，不重新开始。

当前开发库没有 PRACTICE 持久行，步骤 3～4 的成功态由 H2 集成测试覆盖；T10C.2 如需真实浏览器成功演示，应复用既有安全 Seed 机制创建最小课程练习并在验收后精确清理，不能重导题库或清空现有测评。
