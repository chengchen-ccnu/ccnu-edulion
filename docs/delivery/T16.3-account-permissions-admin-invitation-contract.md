# T16.3 账号权限与管理员邀请后端契约

## 目标与边界

2026-10-02，分支 `codex/t16.3-account-permissions-admin-invitation-contract`，保留准备提交 `adf8221`。实现已完成，最终全仓回归、提交及 CI 结果见下方追加记录。用户“全部按建议”确认四项产品选择，见 [契约评审](../api/T16.3-contract-review.md)。

普通账号仅 STUDENT、STUDENT+TEACHER；DISABLED 无有效能力。ADMIN 独立同权，不具备学习、教学、教师申请能力。首次教学授予仍走 T16.2 真实审核，恢复读取不可变 APPROVED 决定。未实现 Vue、站内消息消费、课程审核、注销或后续页面；页面规格与路由不变。

## 架构与状态

1. Gateway 鉴权/限流并路由 IAM。IAM 管理接口再核验当前数据库身份与 sessionVersion，不仅信任旧 JWT 角色。
2. 预览锁 ADMIN 公共角色行、目标 user；Course 内部 API 给出课程 ID，Learning 自己聚合去重 ACTIVE 学生数。预览五分钟、最多1000门，超出/依赖失败503，不返回假零。确认重读影响，变化或 revision 不符409；跨域读取不是原子快照。
3. 确认、10～500字原因、账号/会话变化、审计、accessRevision、suspensionId、协调记录及 Outbox 同 IAM 事务提交。不删除课程/报名/草稿/成绩/资格。clientRequestId 精确重放无重复副作用，异载荷409。
4. 课程命令先返回 PENDING。Worker 先持久化次数和30秒租期，再按原周期/水位调用既有协议；准确回执才 APPLIED。超时可能已提交，仍重放同一周期。自动三次、FAILED 后显式再补偿三次，总上限六次。FAILED 不自动回滚资格或宣称成功；禁止覆盖未完成周期，需要排查原命令。无课程动作 NOT_REQUIRED。
5. 撤权/封禁立即撤教学与会话；普通 UNBAN 仅 STUDENT，课程仍暂停。RESTORE_TEACHING 在 Course 确认前不授 TEACHER，确认后复核批准、账号和周期，再授能/撤会话。仅恢复该周期的已发布课程，草稿不变。沿用 T16.1 暂停停止计时、实际区间顺延；APPLIED 是 Course 提交/Outbox 确认，不等于全部消费者/通知已处理。
6. 管理变更/邀请/批准共用 ADMIN 行锁，READ_COMMITTED 锁内计数保护最后可用管理员、禁止自封禁。普通命令/公开注册不能创建 ADMIN。

### 会话竞争修复

登录/验证码登录/刷新先锁 user，再复核当前密码/状态/刷新事实；所有撤销及身份绑定沿用同一锁序。`SessionVersionPublication` 先提交签发并归还连接，再在新事务锁 user、读取当前已提交版本发布 Redis，不回填旧快照。提交与发布间撤销时，新返回 JWT 也可能已经失效，这是正确安全语义。Redis 缺失/故障继续安全拒绝；发布失败503，已提交 Refresh Session 不伪称回滚。两条连接支持四路并发，不在提交回调借第二连接。

## 邀请与初始化

任何已绑定邮箱409，不转换账号。复用SMTP发43字符随机凭证，数据库只存HMAC；秘密仅POST正文、不进URL/日志/响应。24小时到期、60秒重发冷却、最多六次发送；重发废旧秘密。PENDING/SENT/FAILED明确区分，SMTP接受不等于收件箱送达；进程中断保留PENDING、显式重发，不无限发信。命令幂等与revision/409。

接受需邮箱凭证、自设12～72字密码（UTF-8不超过72字节）；账号、已验证邮箱、独立ADMIN、单次消费和审计原子提交，核验邀请者仍有效，不自动登录；错/过期/重放422。首位初始化默认关闭，无HTTP路由：CLI `--initialize-first-admin` + `IAM_FIRST_ADMINISTRATOR_ENABLED=true`、EMAIL、REQUEST_ID，仍须验证邮箱、自设密码。已有任何ADMIN（含封禁）拒绝。真实库不删管理员制造“首位”，成功/并发边界用独立H2验证。
