## 功能与调用流程

- 顶栏第四槽改为“题库”，固定顺序不变。`/practice` 只读取公共 SYSTEM 题摘要，学段/年级/题型/难度与分页写入 URL，清除不匹配年级；从列表打开 `/practice/questions/:questionId`。
- 独立详情展示安全题干、选项、有序组合小问、知识点、内联与补充图片、音频/附件。复用 SafeAssessmentContent 的受控富文本，媒体通过根题领域授权取得短期地址，再转为 Blob URL；切题、离页中止请求并释放本地 URL，晚到响应不恢复已离开的内容。
- `/courses/:courseId` 为已报名且具备学习能力的用户显示“课程练习”，进入 `/learn/:courseId/tasks?type=PRACTICE`。列表由服务端按该课程过滤；省略 type 继续原 HOMEWORK/EXAM。切课程或切任务类型立即清除原摘要，避免旧任务被展示在新课程上下文。
- 课程练习复用既有作答/最后结果页面，返回时保留 PRACTICE 查询；不改答案保存、评分或 HOMEWORK/EXAM 公布裁决。
- 旧 `/practice/:assessmentId` 只调用 entry 投影，再按服务端 courseId/id 跳往课程任务或最后结果；URL 自带 courseId 不构成归属依据。失败时展示可恢复错误，不枚举所有测评。
- 首次加载失败不会同时显示“没有题目”；同一范围的刷新失败保留已加载内容形成 partial-error。

## 复用接口与差异

| 使用处 | Gateway 接口 | 本轮变更 |
|---|---|---|
| 公共题列表/详情 | GET `/api/v1/learning/system-questions`、`/{questionId}` | 新页面消费既有安全投影 |
| 公共媒体 | POST `/api/v1/learning/system-questions/{questionId}/media/{mediaId}/access-grants` | 复用 T10C.1 领域授权 |
| 课程练习清单 | GET `/api/v1/learning/courses/{courseId}/tasks?type=PRACTICE` | 使用服务端过滤，不取全课程列表 |
| 课程作答/结果 | 原 course task 详情、开始、草稿、提交和最后结果接口 | 复用已有答题器与服务端裁决 |
| 旧深链迁移 | GET `/api/v1/learning/assessments/{assessmentId}/entry` | 只读归属投影 |

没有新增 OpenAPI 字段、DTO、Java/Gateway 逻辑、数据库表或迁移。API 客户端只增加生成 schema 的类型别名导出，未手写或修改生成 DTO，生成文件与 HEAD 一致。

公共单题提交、自动评分和无课程自主组题仍缺少业务契约；页面只提供浏览，并明确“在线作答与自主组题尚未开放”，不提供假按钮。错题有限重做保持原能力；Agent、组题模型和评分流程没有在本任务实现。公共知识点展示复用返回字段，本轮未发明公共知识点查询接口或选择器。
