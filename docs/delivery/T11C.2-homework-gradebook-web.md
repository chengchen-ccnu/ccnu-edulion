## 目标、边界和调用流程

消费冻结的 OpenAPI 0.21.1，不修改页面规格、领域契约、Flyway 或 Learning 生产实现。不新增历史 attempt UI、附件作业、排名、异步 XLSX、第二套答题器或批改器。本轮额外修复成绩册所需的 Gateway 路由/教学能力/CORS 响应头，增加显式启用的 Learning 测试 Fixture，并仅在既有教师批改面板中接入生成的单份 attempt 读取客户端。

- 学生 `/learn/:courseId/tasks` 调用课程任务列表，HOMEWORK/EXAM 位于课程学习上下文，PRACTICE 保留 `/practice`。
- `/learn/:courseId/tasks/:assessmentId` 复用 `PracticeAttemptPage`、服务端 deadline、保存控制器和题目渲染；调用课程任务详情/开始以及已有 draft/submission API。
- `/learn/:courseId/tasks/:assessmentId/result` 调用最后有效结果 API，不接受 attempt ID，复用安全结果投影。
- 课程详情只提供报名后的入口；当前课时区域传递精确 `currentLessonId`。
- 教师 `/teacher/gradebook` 调用 `GET /api/v1/teacher/gradebook` 和 `/export`，显示本人课程 HOMEWORK/EXAM 矩阵及服务端汇总。单元格复用 `/teacher/assessments?courseId=&assessmentId=&attemptId=&panel=grading`。

所有浏览器请求经 Gateway；Learning 通过 HTTP 读取 Course/IAM，不跨服务查表。共享 API 类型来自生成客户端，不手写领域 DTO。

## 本轮修复与人工可读性检查

1. Gateway 缺少成绩册/导出路由：加入两个精确路径到 Learning 路由和 `teaching:access` 检查，CORS 暴露 `Content-Disposition`。不放宽 Origin、Cookie 或权限。测试先复现学生请求错误落入 404，再验证匿名 401、学生 403、教学能力转发成功。
2. CSV text 解码消耗 BOM：Blob 重编码时补一个 UTF-8 BOM。字节回归先失败于 `232,175,190`，修复后为 `239,187,191`。
3. 下载取消竞态：取消立即结束本地状态，旧请求 catch/finally 不再覆盖新控制器或创建下载。组件测试覆盖 abort、迟到成功不下载、卸载中止、成功撤销 Object URL。
4. SCORE 深链刷新后实际顺序错误：先以安全排序确认 READY，再按 URL 的 SCORE 重读；PENDING 只禁用成绩排序，保留其他排序。清空课程 ID 时中止旧读取。

已人工检查修改处中文注释：BOM/取消副作用、两阶段排序、Gateway 权限与响应头、Fixture 专用库/事务/清理边界都有说明；测试替身明确不等同真实验收。未修改生成代码。
