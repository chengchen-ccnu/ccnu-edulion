# T12B 结果页题头与答案排版优化

日期：2026-10-14（承接 2026-10-13 用户截图反馈）。分支：`codex/t17c2-account-permissions-web`；按用户提交合并要求归入 [PR #90](https://github.com/chengchen-ccnu/ccnu-edulion/pull/90)，CI 与合并状态以 PR 记录为准。

## 目标与实现

原结果页题头误用列表卡片 `.72rem` 小字，三个字段分散在行首、中间、行尾，“1 分”没有含义标签。默认 16px 根字号下实际只有 11.52px。

仅修改 `AttemptResultPage.vue` 与学生端 `styles.css`：

- 题号改为 1.5rem 标题；“本题满分”“本题得分”采用成组的语义化定义列表，标签 1rem、数值 1.5rem，空得分显示“待批改”。
- 批改状态以带文字的状态标签紧邻“我的答案”，移除单独占据大片空间的评分面板。单个答案不额外显示列表序号，多个答案保留顺序。
- 参考答案与解题解析分段，以标题、分隔线、行距和边距建立层次；状态同时有文字和颜色。小屏题头上下排列，题号和翻题按钮最小 44px，保留可见键盘焦点。
- 成绩、正确性和参考答案仍各自受既有 `gradeVisible`、`answerVisible` 控制。复用先前修复的媒体渲染与授权，不重新评分或写入答案。

页面职责与两种结果视图路由均未改变；自主练习和课程任务仍复用同一结果组件。无 API、DTO、事件或数据库迁移调整。
