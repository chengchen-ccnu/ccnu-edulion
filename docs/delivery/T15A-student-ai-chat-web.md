# T15A 独立 AI 答疑前端

日期：2026-09-11。状态：前置条件已满足，业务分支已准备，尚未实现。

## 目标与功能边界

T15A 在学生端固定第五导航槽启用“AI 答疑”，交付 `/ai` 会话入口和 `/ai/conversations/:conversationId` 独立会话页。页面只消费 OpenAPI 0.23.2 生成客户端及既有 Gateway、Agent Access、Media 和 Python 运行时，不新增或改写后端契约。

本任务包含最近会话、新建会话、历史消息、文本与公式安全展示、本人上传题图、经授权来源、讲解偏好、九类 SSE 状态、停止、断线后的已保存事件恢复、部分回答标识和最后一问重新生成。独立会话可继续历史，不套用 T15B 悬浮窗的 30 分钟换新规则。

本任务不实现普通题目悬浮窗、课程内嵌 AI、HOMEWORK/EXAM 答疑入口、画像或长期记忆查看、人工转交、自主组题、自动提交或评分，也不复制 SSE、上传或 DTO 实现。

## 实施与验收约束

1. 所有 REST/SSE 字段使用生成契约；统一流适配层必须按 `eventType` 收窄九类事件，验证连续 sequence 和唯一终态，不展示内部推理、提示词、工具原始返回或隐藏画像。
2. 同一会话只允许一轮生成。发送新问题前先停止当前回答；多标签 409 不排队。页面离开必须取消仍在进行的请求并释放上传请求、定时器和临时 Blob URL。
3. 断线后只读取服务端已保存事件，不自动重新调用模型。成功保存的部分回答显示“回答已中断”；重新生成使用专用接口、新请求 ID 并明确计入一次新运行。
4. 图片必须通过既有 Media 上传会话和 OSS 直传，发送消息只携带稳定 `mediaId`。不得接受外部 URL、`data:`、SVG/GIF，页面、日志和缓存不得保存 Token、Object Key、Bucket 或永久签名 URL。
5. 明确讲解偏好只显示 `GUIDED_STEP_BY_STEP` 与 `COMPLETE_SOLUTION`，使用 revision/409 和稳定请求 ID；不得暴露系统推断偏好、画像、证据或长期记忆。
6. 必须覆盖深链接、刷新恢复、分页历史、loading/empty/partial-error、401/403/404/409/422/429/offline/5xx、手机/平板/桌面和键盘焦点。真实验收至少覆盖正常文字、公式、图片、授权来源、停止、断线恢复、部分回答、重生成和偏好冲突。

## 数据、环境与后续依赖

当前准备阶段没有连接或修改 MySQL、Redis、RabbitMQ、Qdrant、Neo4j、OSS，也没有调用模型或创建伪数据。实施验收如需临时会话、消息、run、媒体、Redis key 或 OSS 对象，必须使用专用开发环境、稳定测试标识并在结束后按 ID/前缀精确清理；不得清库、`FLUSHDB` 或枚举删除 Bucket。
