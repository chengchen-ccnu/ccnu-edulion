# T14.2.5 Agent 题目上下文安全回显契约

日期：2026-09-12。状态：实现完成，Ready PR #66 等待评审；不自行合并。

## 目标与功能边界

OpenAPI 从 0.23.2 向前升级到 0.23.3。本人 `PRACTICE_FLOATING` 会话的历史 USER 消息现在可返回与持久化 `questionVersionId` 精确对应的题型、题干、选项、有序组合小问及允许展示的题目媒体绑定。投影不包含答案、解析、成绩/对错、Object Key、Bucket、永久或签名 URL、Python 私有状态、提示词、画像或工具原始结果。

本任务没有实现 T15B Vue 悬浮窗，没有改课程播放器、HOMEWORK、EXAM、自主组题或评分，也没有增加会话、题库、媒体客户端、数据库迁移、Redis、RabbitMQ、Qdrant、Neo4j 或 OSS 结构。

## 架构与调用流程

1. Agent Access 先按 owner 读取会话和当前消息页；非本人会话在调用 Learning 前统一返回 404。
2. 仅对 `PRACTICE_FLOATING` 的 USER 消息读取已保存 `questionId + questionVersionId`，按页去重后通过现有 `AgentDomainClient` 一次调用 Learning 内部 `POST /internal/v1/agent-access/question-versions:project`。批次上限 100，与外部消息页上限一致，不产生逐消息 HTTP N+1。
3. Learning 只读取自身题目聚合与不可变版本事实。根题必须仍为 `ACTIVE SYSTEM`，题目 ID 与版本 ID 必须同时匹配；组合题按父版本保存的顺序解析确切子版本。单项缺失、错配或归档时不返回该项，Agent Access 将对应消息标记为 `UNAVAILABLE + question=null`，禁止回退当前版本或伪造空题目。
4. 历史题图使用 `POST /api/v1/ai/conversations/{conversationId}/messages/{messageId}/question-media/{mediaId}/access-grants`。Agent Access 从本人已保存 USER 消息派生题目和版本，Learning 再校验该历史版本的正文媒体绑定、用途和处置方式，最后复用既有 Media 短期授权。浏览器不能提交或覆盖题目身份、版本、用途或可见性。
5. 重新生成通过同一精确历史版本批量投影与媒体授权恢复可信上下文，随后仍由既有稳定上下文比较保护；原消息、run、额度、Redis 并发、SSE 与取消语义不变。

## 外部与内部契约

- OpenAPI 0.23.3 为 `AgentMessage` 增加可选 `questionContextProjection`。`AVAILABLE` 必须携带完整安全题目；`UNAVAILABLE` 必须携带 `question=null`。
- 新增 `AgentQuestionContextQuestion/Child/Option/Media` 生成类型。媒体仅含 Learning 绑定行 ID、稳定 `mediaId`、用途和顺序。
- 新增消息绑定题目媒体授权端点，返回既有 `MediaAccessGrant`，短期 URL 只存在于授权响应，不进入历史投影或持久化上下文。
- Learning 内部批量投影与历史媒体授权继续使用既有 Agent Access 服务身份和 `PLATFORM_AGENT_DOMAIN_SERVICE_TOKEN`；未新增环境变量。Gateway 既有 `/api/v1/ai/**` 路由与 `learning:access` 权限规则自动覆盖新端点。

## 数据库、环境与启动

未新增或修改数据库表、Flyway、Seed、Redis Key、MQ 事件、索引或 OSS 对象。Learning 的不可变 `question_version` 与既有媒体绑定仍是事实源，Agent Access 继续只保存稳定上下文 ID。

启动方式不变：使用 `scripts/Invoke-WithLocalEnvironment.ps1` 注入本地凭据后启动 Gateway、Learning、Media 与 Agent Access；前端使用 `pnpm.cmd --dir web-apps ...`。未读取、打印或修改 `local.env`，因此没有需要删除或迁移的新增配置。

## 人工演示

1. 准备一条仍为 ACTIVE SYSTEM、但当前版本已经前移的历史题目版本，并在本人 `PRACTICE_FLOATING` 会话中保存该版本消息。
2. 读取消息页，确认 `context.questionVersionId` 与 `questionContextProjection.question.questionVersionId` 均为历史版本，题干不是当前版本；展开组合题时顺序不变。
3. 对投影中的题图调用消息绑定授权端点，确认成功取得短期 Blob 访问；替换 conversationId、messageId 或 mediaId 时统一失败且不泄露题目内容。
4. 归档题目或模拟 Learning 不可用后重读，确认消息仍可读但投影明确为 `UNAVAILABLE`，页面不得改查公共题当前版本。

## 可读性、风险与后续

新增公共方法、批量解析、历史授权和重新生成恢复路径均补充了中文 Javadoc；生成文件未手工补注释。人工检查确认没有跨库查询或敏感字段进入公开 DTO。

已知风险：自动化使用 H2 与媒体端口替身验证边界，未在本任务创建真实开发数据或 OSS 对象；部署前仍应在 T15B 真实验收中用既有 SYSTEM 历史题图复核 Gateway→Agent Access→Learning→Media 的短期授权链路。T15B 只能消费 OpenAPI 0.23.3 生成类型，不得回退到公共题目当前详情拼装历史卡片。
