# T11C.1.3 教师待批答卷读取契约

## 任务目标与功能边界

本任务为教师人工批改提供单份最终有效答卷读取入口，使测评已经关闭、草稿结算完成但整场仍有其他待批答案时，owner 教师可以开始批改指定 attempt。本任务不改变成绩公布、参考答案公布、整场 results 门禁或人工批改写入语义，不实现 Vue 页面。

新增接口：

`GET /api/v1/teacher/attempts/{attemptId}`

响应直接复用既有 `AttemptResult`，没有新增结果 DTO、历史 attempt 列表或数据库对象。

## 主要架构与调用流程

1. OpenAPI 从 0.21.0 演进到 0.21.1，声明 `getTeacherAttemptResult` 和既有 `AttemptResult` 响应。
2. Gateway 已有 `/api/v1/teacher/attempts/**` 通用转发和 `teaching:access` 权限门禁，本任务没有增加冗余路由配置。
3. Learning 的 `TeacherAssessmentController` 只负责读取可信身份头和 `attemptId`，调用已有 `LearningAssessmentService.teacherResult`。
4. `teacherResult` 从 attempt 实际关联的 assessment 解析 owner、课程和测评事实；不把 URL 中的 courseId、assessmentId 或 learnerId 当作授权依据。
5. 对 HOMEWORK/EXAM，服务端要求整场 `CLOSED` 且 `settlementStatus=COMPLETED`，再要求 attempt 是该 learner 的 `final_attempt_id`。整场是否还有其他待批答案不参与单份接口门禁。
6. 非 owner、旧 attempt、找不到真实资源关系的请求统一按 404 隐藏；未关闭或未完成结算按既有冻结语义返回 `409 LEARNING.RESULTS_NOT_READY`。
7. 原 `/api/v1/teacher/assessments/{assessmentId}/results` 继续检查整场待批数量，全部人工批改完成前仍返回 `409 LEARNING.RESULTS_NOT_READY`。
8. POST 人工批改仍复用原 `manualGrade`，按 attempt revision 做乐观并发保护，过期 revision 继续返回 `409 LEARNING.GRADING_REVISION_CONFLICT`，不会静默覆盖。

覆盖的 T11C.1.3 场景：

- owner 读取关闭且结算完成、仍待批的最后有效 attempt：200 语义，结果状态为 `PARTIALLY_GRADED`；
- 同一状态下整场 results 仍为 409 `LEARNING.RESULTS_NOT_READY`；
- 非 owner 和旧 attempt：404；
- 未关闭或未完成草稿结算：409 `LEARNING.RESULTS_NOT_READY`；
- 已批改 attempt：正常返回 `GRADED`；
- 人工批改过期 revision：409 `LEARNING.GRADING_REVISION_CONFLICT`；
- 最终 attempt、资源 owner 和真实 attempt→assessment 关系均由服务端事实校验，调用方参数不构成授权依据。

本轮没有建立新的真实多服务 HTTP Fixture；上述状态和安全边界由 Learning H2 集成测试覆盖，Gateway 路由/权限由全仓 Gateway 测试覆盖。

## 人工演示步骤

1. 使用既有测试/演示数据让 owner 教师关闭一场 HOMEWORK 或 EXAM，并确认草稿结算完成但仍有主观题待批。
2. 请求 `GET /api/v1/teacher/attempts/{finalAttemptId}`，应返回 200 和完整 `AttemptResult`，允许状态为 `PARTIALLY_GRADED`。
3. 请求原 `GET /api/v1/teacher/assessments/{assessmentId}/results`，在仍有待批答案时应返回 409 `LEARNING.RESULTS_NOT_READY`。
4. 使用非 owner、旧 attempt、未关闭或未结算状态重复请求，分别确认 404 或冻结契约规定的 409，不观察资源枚举信息。
5. 用返回的 `revision` 提交人工批改，再用旧 revision 重放一次，确认保存冲突为 409 且没有静默覆盖。
