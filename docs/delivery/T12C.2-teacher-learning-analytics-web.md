# T12C.2 教师学情与分析前端

## 目标与边界

分支 `codex/t12c2-teacher-learning-analytics-web`。在页面规格已冻结的 `/teacher/students` 和 `/teacher/analytics` 交付教师本人课程学情，启用教师端固定第 6 槽“学情分析”。只消费 OpenAPI 0.26.1 生成客户端；不增加 REST 接口、手写业务 DTO、成绩册、批改器或浏览器端统计口径。

## 调用与页面

- `AnalyticsCoursePicker` 通过既有教师课程 API 选本人课程；两页经 Gateway、统一认证壳和 `teaching:access` 路由权限访问 Learning 的 9 个教师学情 GET 接口。
- `/teacher/students` 请求 ACTIVE 列表，URL 保存课程、筛选、排序、分页、学生、`overview|lessons|tasks` 和趋势窗口。只请求所选明细；概览才加载个人趋势。列表和各明细的旧请求在切换或离页时中止。
- `/teacher/analytics` 独立加载课程概览、课时分页、任务分页与 7/30/ALL 趋势；课时按钮用 `lessonId` 切换趋势范围。各块失败独立提示，切换后清除旧课程数据。
- 学生编号在 IAM 昵称依赖失败时仍可用；无当前发布版本有明确空态。401/403/404/409/422/429/503 和离线均给出可行动文案，404 不泄露 owner 或学生存在性。成绩、排名、班级均值/极值/分布只按服务端返回的可见性字段展示。趋势条形仅作像素缩放，数字直接展示服务端日/月点。
- 课时/任务表在窄屏横向滚动，导航、表格表头、筛选标签、状态提示及按钮采用语义 HTML；原有导航槽位标签与顺序不变。

实际使用的接口是 `GET /api/v1/teacher/learning/courses/{courseId}/students`、其 `/{learnerId}/overview|lessons|tasks|trend`，以及同课程 `/analytics/overview|lessons|tasks|trend`。owner、ACTIVE、当前发布修订、成绩门禁及持久统计均在 Learning/Course 服务端执行。前端无数据库表、迁移、事件或环境变量改动。

## 启动、数据与清理

Windows 本地凭据仅由 `scripts/Invoke-WithLocalEnvironment.ps1` 提供；需先按 `scripts/Initialize-LocalEnvironment.ps1` 配置本人专用 local/test 环境。运行 Gateway、IAM、Course、Media、Learning 后执行 `pnpm.cmd --dir web-apps --filter @edu/teacher-web run dev`；认证页由 student-web 提供。未修改 `local.env`，本任务结束无需从其中删除或迁移任何配置。

本次没有创建数据库或表。T12C.1 的真实 MySQL 用例在既有 `edu_platform_learning_dev`、Flyway V18 和 Redis DB 4 上通过 3 项；其随机课时/进度/日事实在 `finally` 精确清理。T12C.2 新增的显式环境开关验收夹具仅在该 Learning 专用开发库的既有固定演示课程 `00000000-0000-4000-8000-000000000201` 中短暂插入 1 行 `assessment`、2 行 `assessment_attempt`、2 行 `assessment_participant`，测试一名最终已批与一名仍待批的 ACTIVE 学生。夹具通过 `T12C2_REAL_ACCEPTANCE=true` 和 `T12C2_ACCEPTANCE_RELEASE_FILE` 启用；输出 `T12C2_REAL_FIXTURE_READY` 后可在浏览器验收，创建释放文件后 `finally` 按固定测试 ID 删除五行并断言残留为零。重复运行前还断言测试 assessment ID 不存在。没有插入课程、用户、报名、媒体或其他服务数据；手工创建的《线性代数》课程未修改。重新生成只需在上述专用环境重跑该单项测试。

## 演示

使用已有可登录且有 `teaching:access` 的教师会话，打开 `/teacher/students`，选择本人“七年级代数基础”；通过列表打开学生并切换概览、课时、任务，刷新 URL 检查恢复。进入 `/teacher/analytics` 查看课程、课时、任务，切换 7/30/ALL 与课时趋势。要重现个人已批而班级待批，按上述夹具启动测试、等 READY 后刷新两页，最后创建释放文件并等待清理断言通过。无需输入或记录密码。

## 已知限制与后续依赖

- 真实 Learning JSON 在 nullable 作业/考试平均值为 null 时省略字段，而 OpenAPI 0.26.1 标为必需 nullable。页面已把缺失值按“成绩暂不可用”显示，并加回归用例；后端序列化与契约仍需后续对齐。
- 7/30 趋势只呈现已落库日事实，不回填上线前日历史；ALL 的历史累计可能大于相同日期的 7/30 活动点。页面不补算或伪造历史。
- 完整的生产网络故障/IAM 宕机/Course 503 人工联调未执行；错误映射与昵称降级有组件/单元回归。系统级全链路仍依赖 T18。
