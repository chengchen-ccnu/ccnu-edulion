## 3. 环境与工具复核

- JDK 17、Maven 3.9.4、Node 20.19.5、pnpm 10.22.0 可调用，符合现有仓库基线。
- `Invoke-WithLocalEnvironment.ps1` 可成功加载共享本地环境；MySQL、Course/Media 服务认证、IAM 安全及 RabbitMQ 用户/密码均只检查已配置布尔值，未输出值。
- 本机 TCP 3306、6379、5672 可连接。RabbitMQ host 未显式配置时 `application-local.yml` 默认 `127.0.0.1`，不是缺少必填项。
- 本轮未登录数据库、Redis 或 RabbitMQ，未校验对应开发 Schema 的迁移/权限，也未启动 Gateway/Course/Learning/Media。TCP 可达和配置可加载不等于真实链路验收；T16.1 在受控环境完成认证、迁移和真实用例后才能报告功能通过。
- OSS/FFmpeg 不作为启动任务的额外安装前置；新授权的真实检查可复用已有媒体，保护手工《线性代数》课程（若需短视频，只读取第二课时），不改版本/媒体绑定、不枚举 Bucket。

## 4. 开工范围与验收重点

先评审 OpenAPI/内部 API/事件与必要向前迁移，再实现后端并生成客户端。测试暂停与保存/提交/自动关闭/Worker 并发，当前准时或迟交窗口、EXAM 时限、重复恢复、多次暂停、乱序事件、依赖故障、非授权 caller 和旧链接。已有正式关闭/公布/批改安全规则不松动。全课程/全学生扫描应有界，不能引入新的学生×测评 N+1 写入。

测试仅创建明确开发环境内的最小临时数据，按精确 ID 清理；本轮没有连接或创建数据库、表、伪数据、Redis Key、RabbitMQ 队列/消息或 OSS 对象，因此无需清理。本轮仅文档检查和环境可加载/端口诊断；后端功能测试留在实施任务。
