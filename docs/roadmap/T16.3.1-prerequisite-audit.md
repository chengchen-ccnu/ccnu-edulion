## 1. 目标与依赖

T16.3（PR #82）已有权限决定、持久化协调、按 commandId 查询和有限补偿。T17C.1（PR #88，main `db255c2`）已有管理端应用壳与审核；账号权限槽仍建设中。

具体缺口：IAM 已提交决定但 HTTP 响应丢失，关闭页面或另一管理员接手后，只知道 userId，无法找回原 commandId；PENDING/FAILED 又会阻止后续动作。因此只增加按账号取得最近权限命令的授权读取入口。T16.3.1 验收合并、生成客户端可用后，总控再复审 T17C.2；本任务不实现或启用账号权限页。

只读证据：OpenAPI 0.31.0 权限命令集合仅 POST，AdminUser 无命令定位字段；`AccountPermissionController` 仅预览、提交、按 ID 查询、补偿；`AccountPermissionService.validate` 阻止同账号 PENDING/FAILED 命令后的新动作。IAM V5 已有 `account_permission_command`、`account_permission_retry` 及按账号索引。此次未制造真实失败命令，不把代码审计写成真实故障复现。

## 2. 确认范围与待评审契约

- 仅新增一个按目标 userId 读取最近权限命令的只读入口，复用 `AccountPermissionCommand` 安全投影。建议 GET `/api/v1/admin/users/{userId}/permission-commands/latest`，有命令 200、账号存在但无命令 204、未知账号 404；路径、排序、空值及错误语义必须先在 OpenAPI 评审并记录，以上不是已发布 API。
- 使用当前有效管理员授权，允许不同管理员接手，不能限制为原操作者。未登录、非管理员、封禁/失效管理员仍走既有安全边界；不能只信任旧 JWT 中的角色。
- 按账号决定 revision 确定最近次序，并提供稳定次序；精确过滤目标账号。不仅查 FAILED，也返回 PENDING/APPLIED/NOT_REQUIRED。单次读取返回当时事实，状态可被既有协调器随后推进，不能承诺冻结快照。
- 响应不含原因、request_json、联系方式、凭据或内部响应正文。查询不写命令、不增加 attempts、不启动补偿、不触发 Course 写入；取得 commandId 后继续使用既有按 ID 查询及 retry。
- 保持自动最多 3 次、显式补偿最多追加 3 次、总计 6 次；FAILED、expectedAttempts、幂等、并发 409、原 accessRevision/suspensionId 等规则不变。202 不等于已协调，APPLIED 也不等于所有 Learning 消费者完成。
- 不新增页面/路由/导航、全量命令历史、管理员邀请、任意角色编辑、运维补偿系统、其他业务系统或第二套 DTO/状态机。不开新 MQ/Redis 链路，不跨服务查表，不默认新增表/迁移/缓存/hash/gate。仅确有查询性能证据时评估向前增加索引，禁止改 IAM V5。

## 3. 验收与交付要求

覆盖无命令/未知账号、当前管理员权限及旧会话失效、两管理员交接、目标账号隔离、多命令确定排序、四种状态、响应丢失后仅凭 userId 恢复；证明 GET 不改变命令/预算/课程事实。回归原命令查询、补偿幂等、expectedAttempts 冲突及六次上限。H2/Mock 和真实 Gateway→IAM→MySQL 验收分别记录，不能互相冒充。测试应证明行为边界，不机械镜像 SQL。

契约先行：更新并评审 OpenAPI、记录 `docs/api/T16.3.1-contract-review.md`，再做最小 IAM 实现和 Gateway 验证，生成客户端、核验同契约 Mock。Java 全仓 `clean verify`；前端执行 `generate:api`、`typecheck`、`test`、`build`，启动 Mock 核验新操作；提交生成物后执行 `check:api`。实际命令、计数、条件跳过、外部依赖与未执行项均如实记录。

真实验收只在明确专用 dev/test 库用最小合成账号/命令 Fixture，并提供幂等清理/重建；涉及跨域事实时只能经原有 API/事件创建，不伪造生产授权。需要凭据的命令通过 `scripts/Invoke-WithLocalEnvironment.ps1`，不得读取/输出秘密。不得操作唯一原管理员、手工《线性代数》或历史 Outbox，不 purge/FLUSHDB/全表清理。查询补口无需新增 OSS、SMTP、模型、Qdrant、Neo4j 或 FFmpeg 依赖。
