> 本文保留后段访谈纠偏轨迹，Q1～Q91 规则已在目标设计按主题及题号范围追溯。实现状态以 backlog/verification 为准。

## 独立 AI 页面：Q72 最新调整

- 学生通过独立 AI 页面进行聊天答疑，不把聊天窗口嵌入课程学习页。
- 会话不自动绑定正在浏览的课程或课时，切换课时不改变 AI 会话上下文，不监听其他课程标签页来补齐提问对象。
- 复用 page-specs 中已有的学生端第五个固定导航槽位“AI 答疑”（`/ai`），以及独立会话路由 `/ai/conversations/:conversationId`。不新增第二套全局顶栏或重复 AI 入口。
- 2026-09-08 总控已将 page-specs/backlog 的 T15B 改为普通自主练习题悬浮答疑，撤销课程内嵌 AI；代码尚未实现新方案。
- Q90 已确认：保留用户主动询问时检索已授权课程文字资料的能力。仅问题确需课程资料时查询，目标不明确时先澄清；Java 校验当前访问权限后提供内容。普通数学提问不自动附带正在浏览的课程，没有可用文字材料时说明看不到视频讲解。课程播放器不增加 Agent 入口。

## 会话运行与中断：Q70～Q71

- 同一会话同时只运行一轮。生成期间允许编辑输入，发送前先停止当前回答；不自动排队。
- 多标签页同时发送时，服务端拒绝第二次运行并提示此会话正在回答。不同会话隔离运行状态，仍受用户总并发额度约束。
- 停止或断线后保留已经生成并成功保存的部分回答，标记“回答已中断”；检测断线后取消后续模型和工具调用。
- 重开页面读取已保存记录，不自动重新生成或重复执行模型请求。重新生成由学生明确触发，“继续”作为新一轮消息。
- 中断输出不算完整答案，不直接提取为已验证的掌握证据。进程崩溃可能丢失尚未保存的末尾片段，不承诺逐字恢复。

## 后续独立任务：公共题库自主练习 Skill（Q73～Q74）

状态：已分配 T14.3“公共题库自主组题 Skill 与确认契约”和 T15C“自主练习建议与创建结果卡片”，均待开始。当前只记录需求，不创建运行时 Skill、不实现组题接口或页面。首个 Agent 答疑交付不得宣称已经具备正式创建练习能力，入口应在该任务完成后启用。

这里的 Skill 属于平台 Python Agent 运行时的可复用能力包：按需加载说明、槽位规则与允许调用的工具。它与 Codex 开发期的 skill-creator 不同；后续可以使用 skill-creator 辅助编写技能材料，但不能假定 Codex 技能会自动成为平台运行时能力。

职责：Practice Coach 按需选择组题 Skill，Skill 指导槽位补齐、候选查询和创建说明；Java 校验并保存待确认动作，学生确认后由 Learning 创建普通自主练习。权限、幂等、参数范围、题目可用性和正式写入由服务端代码执行，不能仅靠技能文本约束。只加载项目维护的技能，不在请求中自动安装用户或模型提供的脚本。

确认的产品规则：

- 只从平台正式 SYSTEM 公共题库选题；不以教师私有题或模型现场生成题替代。保持 Agent 首期初中数学范围。
- 主题优先取学生明确要求，其次取当前对话里明确的题目或主题；仍不明确就询问，不从课程页面偷偷推断。
- 难度默认中等，明确要求或近期有效作答证据支持时调整。
- 默认 5 道，每次 1～20 道主问题，组合题作为一道主问题且不拆散。
- 同一套练习不重复选题，尽量避开近期做过的题。
- 确认前展示实际可用数量；题目不足时说明并允许调整，不能静默扩大范围。创建时条件或可用数量发生实质变化，需要更新说明并重新确认。
- 首期无倒计时，复用现有普通练习作答和评分，不与课程 HOMEWORK/EXAM 合并，不创建第二套答题器。
- 创建成功在会话显示主题、实际题数和“开始练习”结果卡片，点击进入现有练习页面，不强制跳转。
- 请求超时且结果未知时查询同一次操作，不重复创建；失败保留已确认条件和可重试状态。
- 待确认动作默认 10 分钟过期；过期后重新检查题库并展示确认说明。沿用先前已接受的 Java 两阶段确认、revision 与创建幂等规则。

## 来源与状态展示：Q75

- 展示“正在查找相关知识”“正在检查解题过程”等简明状态。
- 只显示有事实依据且经授权的知识点、题目或资料来源；若最终保留课程资料检索，课程/课时引用也需按当前访问权限裁剪。
- 来源失效或无权限时不提供可点击入口；没有可靠检索来源时明确说明，不编造引用。
- 不展示内部提示词、模型内部推理、工具原始返回或隐藏画像。

## 练习题悬浮答疑：Q77～Q87 最新决定

- 保留顶部独立 AI 页面；另在普通自主练习作答区域提供右下角悬浮按钮。HOMEWORK、EXAM、课程播放器不增加入口；结果页、错题本入口后移。
- 用户明确需要从公共题库任意打开独立题目练习，不能把此需求等同于现有测评列表。后续应单独补齐公共题库浏览与单题自主练习，不能声称已有完整前端。
- 悬浮窗聊天记录持久保存，刷新可恢复，并可从独立 AI 页查看及打开同一会话。真正发送消息才创建会话，打开面板不创建空记录。
- Q79/Q85 的最新用户纠正：切题、切换练习作答不创建新会话，不以 assessmentId、attemptId 或 questionId 划分会话。是否沿用仅由 Q84 的空闲过期规则决定。切题不取消正在生成的回答，也不删除历史。
- 空闲期限默认 30 分钟、可配置，从最近运行结束开始计时；没有运行时使用最近有效聊天交互。生成中不换会话，打开窗口、切题、浏览历史不刷新期限。超时后旧记录仍可在独立 AI 页查看；再次实际发送才创建新会话。
- Q91 已确认：上述 30 分钟规则仅控制悬浮窗临时会话的自动沿用。独立 AI 页面不受该期限限制，学生明确打开历史会话后可继续交流；历史消息仍遵守此前确认的保留期限和摘要恢复机制。临时会话过期不删除历史，也不改变已存消息的题目上下文。
- Q86 最新展示纠正：独立题目不使用“第 1 题/第 2 题”等试卷内编号作为标识。输入区提供默认折叠的“附带题目”控件，点击展开题干、选项、组合题结构和授权题图等可辨识内容。消息保存发送时的稳定题目 ID/版本及上下文，切题不得修改历史消息所指题目。
- 当前题目上下文由 Java 校验，默认不自动发送学生正在编辑的答案。学生可明确附上自己的作答草稿；草稿不能伪装成正式提交或评分事实。
- 沿用既定讲解偏好；快捷提问可提供提示、题意说明、检查思路，检查思路须有学生附上的过程。打开面板不自动调用模型。
- 桌面使用小面板、清晰入口和可调整尺寸；移动端使用接近全屏的对话面板。首期不做自由拖拽或多窗口。
- 关闭窗口停止当前流并保留成功保存的片段；这不同于切题。进入完整 AI 页面先停止流再恢复同一会话，不实现跨页面接管流。
- 未发送输入和附加草稿仅在当前页面存活期间保留，关闭重开仍保留；过期后提示将开始新对话。输入已有内容时切题仍保留原关联，明确提示并允许学生主动切换。刷新或关闭浏览器不承诺恢复未发送草稿。
- 多标签页必须按各条消息独立绑定题目上下文，沿用同会话单轮运行限制；不能把其他标签页正在查看的题目覆盖到当前消息。单题练习的提交/评分规则不属于本次 Agent 访谈，应在独立平台任务中审计既有能力。

已分配 T10C.1/T10C.2：先审计和复用已交付公共题库、题目详情与练习能力，再补学生入口；不在 Agent 运行时任务实现。最新导航纠正：顶部第四槽改名“题库”，原课程练习入口移入具体课程详情，“课程练习”只查教师为本课程发布的题目/练习，不汇总所有课程。未授权本次实施业务修复、删除测评、重建题库或迁移数据。
